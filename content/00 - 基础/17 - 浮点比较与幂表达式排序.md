# 浮点近似比较

容差须非负；NaN 不相等，同符号无穷相等。只能用于数值判断，不能作为 sort 比较器。

时间与空间均 O(1)。

```cpp
namespace FloatTools {
// 判断两数是否接近；同符号无穷相等，NaN 不相等
    bool close(long double a, long double b, long double absolute = 1e-12L,
               long double relative = 1e-12L) {
        if (absolute < 0 || relative < 0)
            throw std::invalid_argument("tolerance");
        if (a == b)
            return true;
        if (!std::isfinite(a) || !std::isfinite(b))
            return false;
        return std::abs(a - b) <= absolute + relative * std::max(std::abs(a), std::abs(b));
    }
}
```

## 幂表达式大小排序

x,y,z 为有限正数；同值按编号递增。

0..3 对应 x^(y^z)、x^(z^y)、(x^y)^z、(x^z)^y；4..7、8..11 分别以 y、z 为底，另两个变量的顺序按原 x,y,z 顺序。

时间与空间均 O(1)，共 12 项。

```cpp
namespace FloatTools {
// 比较指数表达式，使用 log(abs(log(value)))，base<1 时反向比较
    std::vector<int> powerOrder(long double x, long double y, long double z) {
        std::array<long double, 3> values{x, y, z};
        for (auto v : values)
            if (!std::isfinite(v) || v <= 0)
                throw std::invalid_argument("positive");
        struct Score {
            int sign, id;
            long double magnitude;
        };
        std::vector<Score> scores;
        for (int i = 0; i < 3; ++i) {
            const std::array<int, 3> left{1, 0, 0}, right{2, 2, 1};
            long double base = values[i], a = values[left[i]], b = values[right[i]];
            int sign = base > 1 ? 1 : base < 1 ? -1 : 0;
            long double first = sign ? std::log(std::abs(std::log(base))) : 0;
            std::array<long double, 4> exponent{b * std::log(a), a * std::log(b),
                                                std::log(a) + std::log(b),
                                                std::log(a) + std::log(b)};
            for (int j = 0; j < 4; ++j)
                scores.push_back({sign, 4 * i + j, first + exponent[j]});
        }
        std::sort(scores.begin(), scores.end(), [](const Score &a, const Score &b) {
            if (a.sign != b.sign)
                return a.sign > b.sign;
            if (a.sign != 0 && a.magnitude != b.magnitude)
                return a.sign > 0 ? a.magnitude > b.magnitude : a.magnitude < b.magnitude;
            return a.id < b.id;
        });
        std::vector<int> order;
        for (auto s : scores)
            order.push_back(s.id);
        return order;
    }
}
```
