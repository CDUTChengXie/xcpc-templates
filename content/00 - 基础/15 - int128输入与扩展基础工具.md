# 连续整数区间异或

参数为 u64，支持 0..ULLONG_MAX；l>r 返回 0，l=0 不计算 l-1。

时间与空间均 O(1)。

```cpp
namespace WideTools {
// 返回 0..n 连续整数的异或，n 为非负 u64，n=0 返回 0
    constexpr u64 xor_n(u64 n) {
        return std::array<u64, 4>{n, 1, n + 1, 0}[n % 4];
    }
    // 返回闭区间 [l,r] 的异或；l>r 返回 0，l=0 时避免计算 l-1
    constexpr u64 xor_range(u64 l, u64 r) {
        return l > r ? 0 : xor_n(r) ^ (l ? xor_n(l - 1) : 0);
    }
}
```

## 三角数行号

n 为 i64；n<=0 返回 0，中间乘法用 i128。

O(log n) 时间，O(1) 空间。

```cpp
namespace WideTools {
// 返回覆盖 n 的最小三角数行号，n<=0 返回0
    i64 triangleIndex(i64 n) {
        if (n <= 0)
            return 0;
        i64 l = 0, r = 4294967296LL;
        while (l < r) {
            i64 m = l + (r - l) / 2;
            if (i128(m) * (m + 1) / 2 >= n)
                r = m;
            else
                l = m + 1;
        }
        return l;
    }
}
```

## 整数向上取对数（u128）

base>1、target 为正无符号 128 位；非法参数抛 invalid_argument，target=1 返回 0。

O(log_base target) 时间，O(1) 空间。

```cpp
namespace WideTools {
    using U = unsigned __int128;
// 返回最小 e>=0 使 base^e>=target，要求 base>1，target 为正无符号128位
    int ceilLog(U base, U target) {
        if (base <= 1 || target == 0)
            throw std::invalid_argument("log");
        U v = 1;
        int e = 0;
        while (v < target) {
            ++e;
            if (v > (target - 1) / base)
                break;
            v *= base;
        }
        return e;
    }
}
```

## 整数对数编号

依赖本文件的「整数向上取对数（u128）」。

a,b 均为大于 1 的 i64；a<=b 时返回 floor(log2(2*ceil(log_a b)-1))，否则返回 -floor(log2(floor(log_b a)))。

O(log_b a+log_a b) 时间，O(1) 空间。

```cpp
namespace WideTools {
// 原 llog 编号：a<=b 时 floor(log2(2*ceil(log_a b)-1))；a>b 时 -floor(log2(floor(log_b a)))
    int logLog(i64 a, i64 b) {
        if (a <= 1 || b <= 1)
            throw std::invalid_argument("loglog");
        if (a <= b) {
            int e = ceilLog(U(a), U(b));
            return int(std::bit_width(unsigned(2 * e - 1))) - 1;
        }
        int e = ceilLog(U(b), U(a) + 1) - 1;
        return -(int(std::bit_width(unsigned(e))) - 1);
    }
}
```
