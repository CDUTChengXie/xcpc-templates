# 公历日期与星期

GNU C++20 chrono；使用向前延伸的公历，年份 1..9999。 DateTools::Date={年,月,日}；星期 0=周一、6=周日；非法日期抛 invalid_argument，跨范围抛 out_of_range。

每次 O(1)。

```cpp
namespace DateTools {
    // 日期三元组 {年, 月, 日}
    using Date = std::array<int, 3>;
    // 将合法公历日期转为天数；非法年月日抛异常
    i64 serial(Date d) {
        using namespace std::chrono;
        if (d[0] < 1 || d[0] > 9999 || d[1] < 1 || d[1] > 12 || d[2] < 1 || d[2] > 31)
            throw std::invalid_argument("date");
        year_month_day ymd{year(d[0]), month(unsigned(d[1])), day(unsigned(d[2]))};
        if (!ymd.ok())
            throw std::invalid_argument("date");
        return sys_days(ymd).time_since_epoch().count();
    }
    // 返回星期：0 周一，6 周日
    int weekday(Date d) {
        return (std::chrono::weekday{std::chrono::sys_days{std::chrono::days{serial(d)}}}
                    .iso_encoding() +
                6) %
               7;
    }
    // 日期加 delta 天；结果必须仍在年份 1..9999 内
    Date add(Date d, i64 delta) {
        using namespace std::chrono;
        i128 s = i128(serial(d)) + delta;
        if (s < serial({1, 1, 1}) || s > serial({9999, 12, 31}))
            throw std::out_of_range("date");
        year_month_day ymd{sys_days{days{i64(s)}}};
        return {int(ymd.year()), int(unsigned(ymd.month())), int(unsigned(ymd.day()))};
    }
    // 返回 a 减 b 的天数，允许负数
    i64 difference(Date a, Date b) {
        return serial(a) - serial(b);
    }
}
```
