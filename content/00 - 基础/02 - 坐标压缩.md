# 坐标压缩

a 为 `vector<i64>`，包含之后会用到的全部值；先收集再构造或 build，不能直接给未收集的值编号。 编号从 0 开始，相等的原值编号相同；get(x) 要求 x 存在，否则断言失败。 若用 add 追加值，要重新 build；旧编号失效。编号差不代表原值差。

add O(1)；build O(m log m)；get / lowerBound / value O(log m)；空间 O(m)。

```cpp
template <class T> struct Compress {
    std::vector<T> a; // build 后，a[id] 为压缩编号 id 对应的原值，升序且去重

    // 创建空对象；使用前需 add + build
    Compress() {}
    // 从迭代器范围构造并立即排序去重
    template <class Iter> Compress(Iter first, Iter last) {
        init(first, last);
    }
    // 从 vector 构造并立即排序去重
    Compress(const std::vector<T> &v) {
        init(v.begin(), v.end());
    }

    // 替换旧数据并重建；旧编号失效
    template <class Iter> void init(Iter first, Iter last) {
        a.assign(first, last);
        build();
    }

    // 追加一个值；追加后须重新 build 才生效
    void add(const T &x) {
        a.push_back(x);
    }

    // 排序去重，使 add 的值生效
    void build() {
        std::sort(a.begin(), a.end());
        a.erase(std::unique(a.begin(), a.end()), a.end());
    }

    // 返回去重后的值域大小
    int size() const {
        return a.size();
    }

    // 第一个 >= x 的编号；x 可以不存在
    int lowerBound(const T &x) const {
        return std::lower_bound(a.begin(), a.end(), x) - a.begin();
    }

    // 是否存在值 x
    bool contains(const T &x) const {
        int p = lowerBound(x);
        return p < size() && a[p] == x;
    }

    // 值 x 的精确编号；x 必须已加入，否则用 lowerBound()
    int get(const T &x) const {
        int p = lowerBound(x);
        assert(p < size() && a[p] == x);
        return p;
    }

    // 编号还原成原值
    const T &value(int p) const {
        assert(0 <= p && p < size());
        return a[p];
    }
};
```
