# 固定大小子集枚举

0<=k<=n<=64，掩码使用 u64。 位编号 [0,n)；k=0 只传入的函数 0 一次；subsets 包含空集。

fixed O(C(n,k)) 时间、O(1) 额外空间；subsets O(2^popcount(mask))。

```cpp
namespace SubsetTools {
    // 回调所有恰有 k 个 1 的 n 位掩码；支持 n=64，非法参数抛异常
    template <class F> void fixed(int n, int k, F visit) {
        if (n < 0 || n > 64 || k < 0 || k > n)
            throw std::invalid_argument("subset");
        if (k == 0) {
            visit(u64(0));
            return;
        }
        u64 x = k == 64 ? ~u64(0) : (u64(1) << k) - 1;
        while (true) {
            visit(x);
            u64 low = x & -x, next = x + low;
            if (next == 0)
                break;
            x = next | (((next ^ x) >> 2) / low);
            if (n < 64 && x >= (u64(1) << n))
                break;
        }
    }
    // 回调 mask 的全部子集；最后一次回调为 0
    template <class F> void subsets(u64 mask, F visit) {
        for (u64 s = mask;; s = (s - 1) & mask) {
            visit(s);
            if (s == 0)
                break;
        }
    }
}
```
