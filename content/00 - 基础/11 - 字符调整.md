# 字符调整

输入为字节字符串，字母只认 ASCII A-Z / a-z；Unicode 文本需专门的 Unicode 库。 字符串下标 [0,size)；非字母原样保留；letterIndex 非字母返回 -1。

转换 O(n)，编号 O(1)。

```cpp
namespace CharTools {
    // 返回 ASCII 小写副本，其他字节保持原样
    std::string lower(std::string s) {
        for (char &c : s)
            if (c >= 'A' && c <= 'Z')
                c += 'a' - 'A';
        return s;
    }
    // 返回 ASCII 大写副本，其他字节保持原样
    std::string upper(std::string s) {
        for (char &c : s)
            if (c >= 'a' && c <= 'z')
                c -= 'a' - 'A';
        return s;
    }
    // 原地翻转奇数或偶数下标处的字母；parity 必须为 0 或 1
    void flipAlternate(std::string &s, int parity = 1) {
        assert(parity == 0 || parity == 1);
        for (size_t i = parity; i < s.size(); i += 2) {
            char &c = s[i];
            if (c >= 'A' && c <= 'Z')
                c += 'a' - 'A';
            else if (c >= 'a' && c <= 'z')
                c -= 'a' - 'A';
        }
    }
    // 返回英文字符的 0..25 编号，非字母返回 -1
    int letterIndex(char c) {
        if (c >= 'A' && c <= 'Z')
            return c - 'A';
        return c >= 'a' && c <= 'z' ? c - 'a' : -1;
    }
    // 返回区分大小写的字母编号：a..z 为 0..25，A..Z 为 26..51
    int caseIndex(char c) {
        return c >= 'a' && c <= 'z' ? c - 'a' : c >= 'A' && c <= 'Z' ? c - 'A' + 26 : -1;
    }
}
```
