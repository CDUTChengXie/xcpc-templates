# 二分

check(x) 返回 x 是否满足题目要求；求最大可行值时小值可行、大值不可行，求最小时方向相反。 实数 eps>0，坐标量级建议不超过 1e18，避免浮点中点无法推进。 整数搜索闭区间 [l,r]；最大值搜索须保证 l 可行，最小值搜索须保证 r 可行。

全不可行时分别返回 l/r，调用前先检查对应端点判无解；实数二分按相对精度停止，精度下限为 double 相邻可表示值。

整数域 O(log(r - l + 1))；实数域 O(log((r - l) / eps))，乘以单次 check 代价。

```cpp
// 求满足 check 的最大 x。check 单调：true...true false...false
inline i64 binarySearchMax(i64 l, i64 r, const std::function<bool(i64)> &check) {
    while (l < r) {
        // 中点向上取整；用算术右移，负数区间才不卡死
        i64 mid = (i64)(((i128)l + r + 1) >> 1);
        if (check(mid)) {
            l = mid;
        } else {
            r = mid - 1;
        }
    }
    return l;
}

// 求满足 check 的最小 x。check 单调：false...false true...true
inline i64 binarySearchMin(i64 l, i64 r, const std::function<bool(i64)> &check) {
    while (l < r) {
        // 中点向下取整；用算术右移，负数区间才不卡死
        i64 mid = (i64)(((i128)l + r) >> 1);
        if (check(mid)) {
            r = mid;
        } else {
            l = mid + 1;
        }
    }
    return l;
}

// 实数域二分：求满足 check 的最小 x，返回值满足 |返回 - 真解| <= eps（相对）
inline double binarySearchReal(double l, double r, double eps,
                               const std::function<bool(double)> &check) {
    while (r - l > std::max(1.0, std::abs(l)) * eps) {
        double mid = l + (r - l) / 2;
        if (mid <= l || mid >= r)
            break;
        if (check(mid)) {
            r = mid;
        } else {
            l = mid;
        }
    }
    return r;
}
```
