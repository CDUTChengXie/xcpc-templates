# 高精度进制转换

源和目标进制均在 2..62；字符表为 0-9A-Za-z。 大小写表示不同数位；允许首个 +/-；拒绝空串、非法字符和越界数位；输出无前导零，负零输出 0。

L 个输入数位、D 个输出数位时 O(LD) 时间、O(L+D) 空间。

```cpp
namespace RadixTools {
    // 转换完整整数；非法输入抛 invalid_argument
    std::string convert(std::string_view s, int from, int to) {
        const std::string alphabet =
            "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz";
        if (from < 2 || from > 62 || to < 2 || to > 62 || s.empty())
            throw std::invalid_argument("radix");
        bool negative = s.front() == '-';
        if (s.front() == '+' || s.front() == '-')
            s.remove_prefix(1);
        if (s.empty())
            throw std::invalid_argument("digits");
        std::vector<int> digits;
        for (char c : s) {
            auto p = alphabet.find(c);
            if (p == std::string::npos || p >= size_t(from))
                throw std::invalid_argument("digit");
            digits.push_back(int(p));
        }
        std::string out;
        size_t first = 0;
        // ponytail: 逐位短除法 O(LD)，超长输入改用大整数分块转换。
        while (first < digits.size()) {
            while (first < digits.size() && digits[first] == 0)
                ++first;
            if (first == digits.size())
                break;
            int remainder = 0;
            for (size_t i = first; i < digits.size(); ++i) {
                int value = remainder * from + digits[i];
                digits[i] = value / to;
                remainder = value % to;
            }
            out.push_back(alphabet[remainder]);
        }
        if (out.empty())
            return "0";
        if (negative)
            out.push_back('-');
        std::reverse(out.begin(), out.end());
        return out;
    }
}
```
