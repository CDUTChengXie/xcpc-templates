# 翻硬币博弈

最多 64 枚硬币；每次翻转一个预设非空掩码，掩码最高位必须当前正面朝上；不能行动者输。 编号 [0,n)，低位在左；状态位 1 表示正面；moves 中每个掩码是一种固定可选操作，重复掩码不影响判定。 单翻、双翻、连续段、距离限制等都要自行列进 moves。

预处理 O(64*m)，单次 value O(64)，找操作 O(64*m)，空间 O(n+m)。

```cpp
struct CoinFlipGame {
    int n;
    std::vector<u64> moves;
    std::vector<int> singleton;
    // 建立固定翻转规则，掩码须非0且不含 n 范围外的位
    CoinFlipGame(int n, const std::vector<u64> &moves) : n(n), moves(moves) {
        if (n < 0 || n > 64)
            throw std::invalid_argument("coins");
        for (u64 mask : moves)
            if (mask == 0 || (n < 64 && (mask >> n)))
                throw std::invalid_argument("mask");
        singleton.resize(n);
        for (int i = 0; i < n; ++i) {
            std::set<int> seen;
            for (u64 mask : moves)
                if (int(std::bit_width(mask)) - 1 == i) {
                    int sg = 0;
                    for (int j = 0; j < i; ++j)
                        if (mask >> j & 1)
                            sg ^= singleton[j];
                    seen.insert(sg);
                }
            while (seen.count(singleton[i]))
                ++singleton[i];
        }
    }
    // 返回状态的 SG，拒绝棋盘范围之外的位
    int value(u64 state) const {
        if (n < 64 && (state >> n))
            throw std::invalid_argument("state");
        int sg = 0;
        for (int i = 0; i < n; ++i)
            if (state >> i & 1)
                sg ^= singleton[i];
        return sg;
    }
    // 返回一条合法且使 SG 归零的翻法，不修改状态
    std::optional<u64> move(u64 state) const {
        if (value(state) == 0)
            return std::nullopt;
        for (u64 mask : moves)
            if ((state >> (std::bit_width(mask) - 1) & 1) && value(state ^ mask) == 0)
                return mask;
        assert(false);
        return std::nullopt;
    }
};
```
