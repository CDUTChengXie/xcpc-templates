# 取模还原分数

M>1，A>=0，B>=1，2*A*B<M；违反唯一恢复条件会 assert。 residue 可为负；恢复最简 num/den，其中 |num|<=A、1<=den<=B 且 den 与 M 互素；找不到为空 optional。

O(log M) 时间、O(1) 空间。

```cpp
namespace rational_reconstruction {
    // 返回有界分数 num/den，无符合边界的分数返回 nullopt。
    std::optional<std::pair<long long, long long>> restore(long long x, long long M, long long A,
                                                           long long B) {
        assert(M > 1 && A >= 0 && B >= 1 && (__int128)2 * A * B < M);
        x %= M;
        if (x < 0)
            x += M;
        __int128 r0 = M, r1 = x, t0 = 0, t1 = 1;
        while (r1 > A) {
            __int128 q = r0 / r1;
            auto r = r0 - q * r1;
            r0 = r1;
            r1 = r;
            auto t = t0 - q * t1;
            t0 = t1;
            t1 = t;
        }
        if (t1 < 0)
            r1 = -r1, t1 = -t1;
        if (t1 < 1 || t1 > B || r1 < -(__int128)A || r1 > A)
            return {};
        long long a = r1, b = t1;
        if (std::gcd(a, b) != 1 || std::gcd(b, M) != 1 || ((__int128)x * b - a) % M)
            return {};
        return std::pair{a, b};
    }
}
```
