# 任意模数行列式（欧几里得消元）

matrix 为方阵，1<=mod<=INT_MAX；元素为 long long，可为负。 matrix[i][j] 是第 i 行第 j 列，下标从 0 开始；不改输入矩阵，不用模逆元；结果在 [0,mod)。 空矩阵返回 1%mod，mod=1 时返回 0。

O(n³ log mod)时间/O(n²)空间，不使用模逆。

```cpp
namespace composite_determinant {
    // 返回方阵行列式模 mod。
    int det(std::vector<std::vector<long long>> a, int mod) {
        assert(mod >= 1);
        int n = a.size();
        for (auto &row : a) {
            assert(row.size() == n);
            for (auto &v : row) {
                v %= mod;
                if (v < 0)
                    v += mod;
            }
        }
        long long ans = 1 % mod;
        bool negative = false;
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j)
                while (a[j][i]) {
                    long long q = a[i][i] / a[j][i];
                    for (int k = i; k < n; ++k) {
                        a[i][k] = (a[i][k] - q * a[j][k]) % mod;
                        if (a[i][k] < 0)
                            a[i][k] += mod;
                    }
                    std::swap(a[i], a[j]);
                    negative = !negative;
                }
            if (!a[i][i])
                return 0;
            ans = ans * a[i][i] % mod;
        }
        return negative && ans ? mod - ans : ans;
    }
}
```
