# SG 函数

正常玩法，无法行动者输；n>=0；moves(x) 返回可走到的状态，每个后继须满足 0<=nx<x，moves(0) 为空。 按编号从小到大计算；返回长度 n+1，sg[i] 是状态 i 的 SG 值；只判断胜负，不返回获胜走法。

O(n + 总转移数) 时间，O(n) 空间；时间戳计算 mex。

```cpp
// 返回长度 n+1 的 SG 表，result[x] 是状态 x 的 SG 值。
std::vector<int> computeSG(int n, const std::function<std::vector<int>(int)> &moves) {
    if (n < 0)
        throw std::invalid_argument("negative state count");
    std::vector<int> sg(size_t(n) + 1), stamp(size_t(n) + 2, -1);
    for (size_t index = 0; index < sg.size(); ++index) {
        int state = int(index);
        for (int next : moves(state)) {
            if (next < 0 || next >= state)
                throw std::invalid_argument("moves must go to a smaller state");
            stamp[sg[next]] = state;
        }
        int value = 0;
        while (stamp[value] == state)
            ++value;
        sg[state] = value;
    }
    return sg;
}
```
