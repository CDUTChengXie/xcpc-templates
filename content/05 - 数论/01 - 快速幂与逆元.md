# 快速幂与逆元

p>=1，指数 b>=0；求逆要求 p 为素数且 a 不被 p 整除。 允许负底数、负乘数，结果在 [0,p)；p=1 返回 0；幂指数为 0 时按 a^0=1 计算。

O(log b) 时间，O(1) 空间；mulMod O(1)。

```cpp
#ifndef XCPC_MODPOW
#define XCPC_MODPOW

// 返回 a*b mod p，结果规范到 [0,p)。
i64 mulMod(i64 a, i64 b, i64 p) {
    i64 r = i64(i128(a) * b % p);
    return r < 0 ? r + p : r;
}

// 返回 a^b mod p。
i64 power(i64 a, i64 b, i64 p) {
    if (p == 1) {
        return 0;
    }
    i64 res = 1 % p;
    for (; b; b >>= 1, a = mulMod(a, a, p)) {
        if (b & 1) {
            res = mulMod(res, a, p);
        }
    }
    return res;
}

#endif // XCPC_MODPOW
```
