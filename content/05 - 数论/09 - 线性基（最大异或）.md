# 线性基（基础版）

插入值和 maxXor 的初始值均在 [0,2^60)；kth 要求 0<=k<2^rank，rank 是独立向量个数。 允许选空集，故第 0 小为 0；insert(0) 返回 false；重复或可由已有数异或得到的值不增加 rank。 kth 自动重建；之后仍可 insert，加入新独立向量会使重建缓存失效。

insert/maxXor O(L)；rebuild O(L^2)，已重建时 kth O(L)；空间 O(L)。

```cpp
// 固定 60 位异或线性基。
struct LinearBasis {
    static constexpr int L = 60;
    std::vector<i64> a;
    bool rebuilt = false;

    // 构造空基。
    LinearBasis() : a(L, 0) {}

    // 插入 x，返回是否增加秩。
    bool insert(i64 x) {
        for (int i = L - 1; i >= 0; i--) {
            if (!(x >> i & 1)) {
                continue;
            }
            if (a[i]) {
                x ^= a[i];
            } else {
                a[i] = x;
                rebuilt = false;
                return true;
            }
        }
        return false;
    }

    // 返回以 init 为基础能得到的最大异或值。
    i64 maxXor(i64 init = 0) const {
        for (int i = L - 1; i >= 0; i--) {
            init = std::max(init, init ^ a[i]);
        }
        return init;
    }

    // 重建便于按位枚举的基。
    void rebuild() {
        if (rebuilt) {
            return;
        }
        rebuilt = true;
        for (int i = 0; i < L; i++) {
            for (int j = i - 1; j >= 0; j--) {
                if (a[i] >> j & 1) {
                    a[i] ^= a[j];
                }
            }
        }
    }

    // 返回第 k 小异或值，k 从 0 开始。
    i64 kth(i64 k) {
        rebuild();
        i64 res = 0;
        int cnt = 0;
        for (int i = 0; i < L; i++) {
            if (a[i]) {
                if (k >> cnt & 1) {
                    res ^= a[i];
                }
                cnt++;
            }
        }
        return res;
    }
};
```
