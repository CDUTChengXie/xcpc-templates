# 十进制大数模幂

a、b 为非空十进制数字串；1<=m<=ULLONG_MAX。 不允许正负号或其他字符；允许前导零；0^0 返回 1 mod m；全程精确整数。

O(|a|+|b|) 时间、O(1) 额外空间。

```cpp
namespace DecimalPower {
    // 检查完整十进制数字串，非法输入抛异常
    void validate(std::string_view s) {
        if (s.empty() || s.find_first_not_of("0123456789") != std::string_view::npos)
            throw std::invalid_argument("decimal");
    }
    // 返回任意长度非负十进制整数模 m
    u64 remainder(std::string_view s, u64 m) {
        if (m == 0)
            throw std::invalid_argument("modulus");
        validate(s);
        u64 value = 0;
        for (char c : s)
            value = u64((static_cast<unsigned __int128>(value) * 10 + c - '0') % m);
        return value;
    }
    // 返回 u64 底数的非负整数幂模 m；m>=1
    u64 power(u64 a, u64 b, u64 m) {
        if (m == 0)
            throw std::invalid_argument("modulus");
        u64 result = 1 % m;
        a %= m;
        while (b) {
            if (b & 1)
                result = u64(static_cast<unsigned __int128>(result) * a % m);
            a = u64(static_cast<unsigned __int128>(a) * a % m);
            b >>= 1;
        }
        return result;
    }
    // 返回长底数、长指数的模幂；不用分解模数
    u64 solve(std::string_view a, std::string_view b, u64 m) {
        u64 base = remainder(a, m);
        validate(b);
        u64 result = 1 % m;
        for (char digit : b)
            result = u64(static_cast<unsigned __int128>(power(result, 10, m)) *
                         power(base, digit - '0', m) % m);
        return result;
    }
}
```
