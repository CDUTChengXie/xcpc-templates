# 左偏树（可并堆）

合并的根须属于同一个 heap，且节点互不重叠；仅支持删除堆顶。 根 0 表示空堆；insert/merge 须接收新根；merge 后输入根不能再独立使用。 top/pop 要求根非零；pop 同时按引用更新根，无需额外赋回。

merge / insert / pop O(log n)，newNode / top O(1)；空间 O(n)。

```cpp
// 单节点池的小根可并堆
template <class T> struct LeftistHeap {
    struct Node {
        T val;
        int l;
        int r;
        int dist;
    };

    std::vector<Node> t;

    // 创建只含 0 号空哨兵的堆池
    LeftistHeap() {
        t.push_back({T(), 0, 0, 0});
    }

    // 新建一个值 v 的单节点堆，返回编号
    int newNode(const T &v) {
        t.push_back({v, 0, 0, 1});
        return t.size() - 1;
    }

    // 合并两个堆（小根堆），返回新根
    int merge(int x, int y) {
        if (!x) {
            return y;
        }
        if (!y) {
            return x;
        }
        if (t[y].val < t[x].val) {
            std::swap(x, y);
        }
        t[x].r = merge(t[x].r, y);
        if (t[t[x].l].dist < t[t[x].r].dist) {
            std::swap(t[x].l, t[x].r);
        }
        t[x].dist = t[t[x].r].dist + 1;
        return x;
    }

    // 插入一个值：merge(root, newNode(v))
    int insert(int rt, const T &v) {
        return merge(rt, newNode(v));
    }

    // 返回堆顶值；rt 必须非零
    T top(int rt) const {
        return t[rt].val;
    }

    // 弹出堆顶，返回 {堆顶值, 新根}；同时原地更新 rt
    std::pair<T, int> pop(int &rt) {
        T v = t[rt].val;
        rt = merge(t[rt].l, t[rt].r);
        return {v, rt};
    }
};
```
