# 单调栈

数组静态且元素可比较；这四个入口均跳过等值元素。 数组与返回下标均从 0 编号；左侧无解为 -1，右侧无解为 n；四个函数均比较严格大小并跳过等值，调用互不影响。

一次遍历 O(n)；空间 O(n)。

```cpp
// 返回每个位置左侧最近严格更小元素的下标，无解 -1
template <class T> std::vector<int> prevLess(const std::vector<T> &a) {
    int n = a.size();
    std::vector<int> l(n);
    std::vector<int> st;
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.back()] >= a[i]) {
            st.pop_back();
        }
        l[i] = st.empty() ? -1 : st.back();
        st.push_back(i);
    }
    return l;
}

// 返回每个位置右侧最近严格更小元素的下标，无解 n
template <class T> std::vector<int> nextLess(const std::vector<T> &a) {
    int n = a.size();
    std::vector<int> r(n);
    std::vector<int> st;
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && a[st.back()] >= a[i]) {
            st.pop_back();
        }
        r[i] = st.empty() ? n : st.back();
        st.push_back(i);
    }
    return r;
}

// 返回每个位置左侧最近严格更大元素的下标，无解 -1
template <class T> std::vector<int> prevGreater(const std::vector<T> &a) {
    int n = a.size();
    std::vector<int> l(n);
    std::vector<int> st;
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.back()] <= a[i]) {
            st.pop_back();
        }
        l[i] = st.empty() ? -1 : st.back();
        st.push_back(i);
    }
    return l;
}

// 返回每个位置右侧最近严格更大元素的下标，无解 n
template <class T> std::vector<int> nextGreater(const std::vector<T> &a) {
    int n = a.size();
    std::vector<int> r(n);
    std::vector<int> st;
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && a[st.back()] <= a[i]) {
            st.pop_back();
        }
        r[i] = st.empty() ? n : st.back();
        st.push_back(i);
    }
    return r;
}
```
