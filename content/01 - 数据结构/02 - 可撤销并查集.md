# 可撤销并查集

先 `RollbackDSU(n)`；合并前用 `time()` 保存状态，用 `merge(u,v)` 合并，最后 `revert(saved)` 撤销。

先记录状态，再合并，最后按记录撤销；只能撤销记录之后的整段合并。 下标 0..n-1；不能单独删除其中一次合并，重置后旧状态编号失效。

find/merge O(log n)，time O(1)，revert O(撤销次数)，空间 O(n)。

```cpp
struct RollbackDSU {
    // f[u] 是并查集父节点；连通块大小读 siz[find(u)]，非代表位置不是当前大小
    std::vector<int> f, siz;
    std::vector<std::array<int, 2>> his;

    // 创建空对象；使用前调用 init(n)
    RollbackDSU() {}
    // 创建 n 个独立集合，编号从 0 到 n-1
    RollbackDSU(int n) {
        init(n);
    }

    // 重置为 n 个独立集合；之前记录的状态编号失效
    void init(int n) {
        f.resize(n);
        std::iota(f.begin(), f.end(), 0);
        siz.assign(n, 1);
        his.clear();
    }

    // 返回 x 所在集合的代表编号；编号相同表示属于同一集合
    int find(int x) {
        while (f[x] != x) {
            x = f[x];
        }
        return x;
    }

    // 合并 x、y 所在集合；成功返回 true，已在同一集合返回 false
    bool merge(int x, int y) {
        x = find(x);
        y = find(y);
        if (x == y) {
            return false;
        }
        if (siz[x] < siz[y]) {
            std::swap(x, y);
        }
        his.push_back({x, y});
        siz[x] += siz[y];
        f[y] = x;
        return true;
    }

    // 记录当前状态，返回供 revert 使用的编号
    int time() {
        return his.size();
    }

    // 撤销 tm 之后的合并；tm 须为尚未被撤销的状态编号，无返回值
    void revert(int tm) {
        while (int(his.size()) > tm) {
            auto [x, y] = his.back();
            his.pop_back();
            f[y] = y;
            siz[x] -= siz[y];
        }
    }
};
```
