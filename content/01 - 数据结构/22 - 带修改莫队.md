# 带修改莫队

所有修改和询问先给出；修改是 a[p]+=delta，赋值须先换算增量；实际值、统计值不溢出 i64。 calc 会逐问重新计算，结果须可转 i64，不能在 calc 中改数组；总耗时包括每次 calc 的开销。

下标从 0 编号，询问 {l,r,t} 使用闭区间 [l,r]，0<=l<=r<a.size()，0<=t<=mods.size()。 t 是已施加的修改条数，t=0 表示初始数组；返回原询问顺序，输入数组保持不变。

O(n + q log q + Σ|Δt| + Σ(|Δl|+|Δr|) + ΣTcalc)；时间/窗口回放最坏 O(q(m+n))，不承诺 1e5 规模。

```cpp
// 带修改询问的排序与时间回放；统计由 calc 按当前数组重算
template <class F>
std::vector<i64> moWithModify(std::vector<i64> a, const std::vector<std::pair<int, i64>> &mods,
                              const std::vector<std::tuple<int, int, int>> &queries, F calc) {
    int n = (int)a.size();
    int q = (int)queries.size();
    if (q == 0) {
        return {};
    }
    int B = std::max(1, (int)std::pow((double)n, 2.0 / 3.0));
    std::vector<int> order(q);
    for (int i = 0; i < q; i++) {
        order[i] = i;
    }
    std::sort(order.begin(), order.end(), [&](int x, int y) {
        auto [lx, rx, tx] = queries[x];
        auto [ly, ry, ty] = queries[y];
        int bx = lx / B, by = ly / B;
        if (bx != by) {
            return bx < by;
        }
        if (rx != ry) {
            // 奇偶块交替升降序，减少右指针往返
            return (bx & 1) ? rx > ry : rx < ry;
        }
        return tx < ty;
    });

    std::vector<i64> ans(q);
    int cl = 0, cr = -1, ct = 0; // 当前窗口 [cl, cr] 与当前时间 ct
    for (int qi : order) {
        auto [l, r, t] = queries[qi];
        // 先调时间，再调区间：这样 calc 看到的数组一定是「当前时间」下的
        while (ct < t) {
            auto [p, d] = mods[ct++];
            a[p] += d;
        }
        while (ct > t) {
            auto [p, d] = mods[--ct];
            a[p] -= d;
        }
        while (cl > l) {
            cl--;
        }
        while (cr < r) {
            cr++;
        }
        while (cl < l) {
            cl++;
        }
        while (cr > r) {
            cr--;
        }
        // ponytail: 每次重算 calc，区间和最坏 O(qn)；大规模改增量 add/del 维护或在线结构。
        ans[qi] = calc(a, cl, cr);
    }
    return ans;
}
```
