# 动态开点线段树

先 `SegmentTree(domain)`；`modify(position,value)` 抬高单点值，`rangeQuery(l,r).maxv` 查询区间最大值。

整数坐标域 [0,domain)，i64 domain>0；值为 int；仅支持取 max，不能赋小值或删除。 区间 [left,right)（含左端，不含右端），0<=left<=right<=domain；位置须在域内。 所有位置初始为 0，负值被零基线压住；空区间、未写区间查询均返回 0。

只按访问过的位置建点，总节点 O(q log V)（q 次操作、值域上界 V）；单次修改 / 查询 O(log V)；空间 O(q log V)。

```cpp
struct Info {
    int maxv = 0;

    // 单位元：maxv = 0，未建节点区间返回它
    Info() {}
    // 构造单个值 x 的叶信息
    Info(int x) : maxv(x) {}
};

// 合并相邻两段，取最大值
Info operator+(const Info &L, const Info &R) {
    return Info(std::max(L.maxv, R.maxv));
}

// 动态开点线段树：值域 [0, n) 单点 chmax + 区间最大值
struct SegmentTree {
    struct Node {
        int lc = 0, rc = 0;
        Info info;
    };

    i64 n;
    int root;
    std::vector<Node> tr;

    // 建值域 [0, n_) 的空树
    SegmentTree(i64 n_) : n(n_) {
        tr.emplace_back();
        root = newNode();
    }

    // 新建一个空节点，返回其编号
    int newNode() {
        tr.emplace_back();
        return int(tr.size()) - 1;
    }

    // 由左右子节点信息重算节点 p
    void pull(int p) {
        tr[p].info = tr[tr[p].lc].info + tr[tr[p].rc].info;
    }

    // 递归在节点 p 覆盖的 [l,r) 内把叶 x 对 v 取 max
    void modify(int p, i64 l, i64 r, i64 x, int v) {
        if (r - l == 1) {
            tr[p].info.maxv = std::max(tr[p].info.maxv, v);
            return;
        }
        i64 m = l + (r - l) / 2;
        if (x < m) {
            if (!tr[p].lc) {
                tr[p].lc = newNode();
            }
            modify(tr[p].lc, l, m, x, v);
        } else {
            if (!tr[p].rc) {
                tr[p].rc = newNode();
            }
            modify(tr[p].rc, m, r, x, v);
        }
        pull(p);
    }

    // 单点 chmax：把位置 x 的值对 v 取 max
    void modify(i64 x, int v) {
        modify(root, 0, n, x, v);
    }

    // 递归查询节点 p 覆盖的 [l,r) 内 [x,y) 的合并信息
    Info rangeQuery(int p, i64 l, i64 r, i64 x, i64 y) const {
        if (!p || l >= y || r <= x) {
            return {};
        }
        if (l >= x && r <= y) {
            return tr[p].info;
        }
        i64 m = l + (r - l) / 2;
        return rangeQuery(tr[p].lc, l, m, x, y) + rangeQuery(tr[p].rc, m, r, x, y);
    }

    // 返回 [x,y) 的最大值；空/未写区间返回单位元
    Info rangeQuery(i64 x, i64 y) const {
        return rangeQuery(root, 0, n, x, y);
    }
};
```
