# 单调队列

数组静态，1<=k<=n；空数组没有合法窗口。 返回长度 n-k+1 的数组；k 从 0 起不合法；第 i 项对应 [i,i+k)。

时间 O(n)，空间 O(n)（返回数组和下标队列）。

```cpp
// 返回每个长度 k 窗口的最大值，第 i 项对应 [i,i+k)
template <class T> std::vector<T> slidingMax(const std::vector<T> &a, int k) {
    int n = a.size();
    std::vector<T> ans(n - k + 1);
    std::vector<int> q(n);
    int h = 0, t = 0;
    for (int i = 0; i < n; i++) {
        while (h < t && a[q[t - 1]] <= a[i]) {
            t--;
        }
        q[t++] = i;
        while (h < t && q[h] <= i - k) {
            h++;
        }
        if (i >= k - 1) {
            ans[i - k + 1] = a[q[h]];
        }
    }
    return ans;
}

// 返回每个长度 k 窗口的最小值，第 i 项对应 [i,i+k)
template <class T> std::vector<T> slidingMin(const std::vector<T> &a, int k) {
    int n = a.size();
    std::vector<T> ans(n - k + 1);
    std::vector<int> q(n);
    int h = 0, t = 0;
    for (int i = 0; i < n; i++) {
        while (h < t && a[q[t - 1]] >= a[i]) {
            t--;
        }
        q[t++] = i;
        while (h < t && q[h] <= i - k) {
            h++;
        }
        if (i >= k - 1) {
            ans[i - k + 1] = a[q[h]];
        }
    }
    return ans;
}
```
