# 最小表示法

只按字符字典序比较，不支持自定义权值；空串合法。 返回 从 0 编号 起点；多个最小表示取最小起点，空串返回 0。

O(n) 时间，空间 O(1)。

```cpp
// 返回字符串 s 的最小循环左移起点。
int minimalRotation(const std::string &s) {
    int n = s.size();
    int i = 0, j = 1, k = 0;
    while (i < n && j < n && k < n) {
        unsigned char a = s[(i + k) % n], b = s[(j + k) % n];
        if (a == b) {
            k++;
        } else if (a < b) {
            j = j + k + 1;
            if (j == i) {
                j++;
            }
            k = 0;
        } else {
            i = i + k + 1;
            if (i == j) {
                i++;
            }
            k = 0;
        }
    }
    return std::min(i, j);
}
```
