# 字符串哈希

先 `StrHash(s)`，再调用 `get(l,r)` 或 `equal(l1,r1,l2,r2)`；字符串改变后重新构造。

StrHash 用于普通 ASCII 文本；哈希可能碰撞；不同对象须使用相同底数和模数。 下标从 0 开始，区间 [l,r)（含左端，不含右端）；equal 同时检查长度；空区间的哈希为 {0,0}。

预处理 O(n)，查询 O(1)，空间 O(n)。

```cpp
// 固定底数 131、双模 1e9+7/1e9+9 的子串哈希。
struct StrHash {
    static constexpr int M1 = 1E9 + 7;
    static constexpr int M2 = 1E9 + 9;
    static constexpr int B = 131;

    int n;
    std::vector<int> p1, p2, h1, h2;

    // 创建空对象，使用前调用 init。
    StrHash() {}
    // 预处理字符串 s，建立双哈希。
    StrHash(const std::string &s) {
        init(s);
    }

    // 用 s 重建哈希表。
    void init(const std::string &s) {
        n = s.size();
        p1.assign(n + 1, 1);
        p2.assign(n + 1, 1);
        h1.assign(n + 1, 0);
        h2.assign(n + 1, 0);
        for (int i = 0; i < n; i++) {
            p1[i + 1] = 1LL * p1[i] * B % M1;
            p2[i + 1] = 1LL * p2[i] * B % M2;
            h1[i + 1] = (1LL * h1[i] * B + s[i]) % M1;
            h2[i + 1] = (1LL * h2[i] * B + s[i]) % M2;
        }
    }

    // 返回 [l,r) 的双哈希。
    std::pair<int, int> get(int l, int r) const {
        int x = (h1[r] + 1LL * (M1 - h1[l]) * p1[r - l]) % M1;
        int y = (h2[r] + 1LL * (M2 - h2[l]) * p2[r - l]) % M2;
        return {x, y};
    }

    // 返回两段长度与双哈希是否都相同；仍可能碰撞。
    bool equal(int l1, int r1, int l2, int r2) const {
        return r1 - l1 == r2 - l2 && get(l1, r1) == get(l2, r2);
    }
};
```

## 可配置字符串哈希（独立版）

仅需统一主模板，可独立复制。

mod[k]>256、1<base[k]<mod[k] 且不超过 int 范围；哈希仍可能碰撞。

按 unsigned char+1 编码所有字节，0-based 半开区间；跨对象比较须参数相同。

预处理 O(n)，get/replaced/equal O(1)，空间 O(n)。

```cpp
// 可配置模数和底数的字符串哈希。
class ConfigurableStrHash {
    string text;
    array<int, 2> mod, base;
    vector<array<int, 2>> power, prefix;

  public:
    // 用指定双模和双底建表；参数相同的对象才可比较。
    ConfigurableStrHash(const string &s, array<int, 2> modulus, array<int, 2> bases)
        : text(s), mod(modulus), base(bases), power(s.size() + 1), prefix(s.size() + 1) {
        power[0] = {1, 1};
        for (int k = 0; k < 2; k++)
            assert(mod[k] > 256 && 1 < base[k] && base[k] < mod[k]);
        for (int i = 0; i < int(s.size()); i++)
            for (int k = 0; k < 2; k++) {
                power[i + 1][k] = i64(power[i][k]) * base[k] % mod[k];
                prefix[i + 1][k] =
                    (i64(prefix[i][k]) * base[k] + static_cast<unsigned char>(s[i]) + 1) % mod[k];
            }
    }
    // 返回 [l,r) 的规范化双哈希；空区间 {0,0}。
    array<int, 2> get(int l, int r) const {
        assert(0 <= l && l <= r && r <= int(text.size()));
        array<int, 2> answer;
        for (int k = 0; k < 2; k++)
            answer[k] =
                (prefix[r][k] - i64(prefix[l][k]) * power[r - l][k] % mod[k] + mod[k]) % mod[k];
        return answer;
    }
    // 返回位置 p 假设替换成 c 后的整体 Hash；对象保持原串。
    array<int, 2> replaced(int p, char c) const {
        assert(0 <= p && p < int(text.size()));
        auto answer = get(0, text.size());
        int delta = int(static_cast<unsigned char>(c)) - int(static_cast<unsigned char>(text[p]));
        for (int k = 0; k < 2; k++) {
            i64 v = (answer[k] + i64(delta) * power[text.size() - p - 1][k]) % mod[k];
            answer[k] = (v + mod[k]) % mod[k];
        }
        return answer;
    }
    // 比较两段长度和双 Hash；true 仍存在碰撞可能。
    bool equal(int l1, int r1, int l2, int r2) const {
        auto a = get(l1, r1), b = get(l2, r2);
        return r1 - l1 == r2 - l2 && a == b;
    }
};
```
