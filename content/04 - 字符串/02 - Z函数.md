# Z函数

text、pattern 为 std::string，按字符精确匹配。 位置从 0 开始；匹配包含重叠，找不到返回空数组；空模式匹配所有边界 0..text.size()。

O(|text|+|pattern|) 时间和空间。

```cpp
// z[i] 为 s 从位置 i 起与整个 s 开头相同的字符数；末尾额外补 0。
std::vector<int> Z(const std::string &s) {
    int n = s.size();
    std::vector<int> z(n + 1);
    z[0] = n;
    for (int i = 1, j = 1; i < n; i++) {
        z[i] = std::max(0, std::min(j + z[j] - i, z[i - j]));
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) {
            z[i]++;
        }
        if (i + z[i] > j + z[j]) {
            j = i;
        }
    }
    return z;
}

// 返回每个文本位置与 pattern 开头相同的字符数；空模式对应全 0。
std::vector<int> prefixMatches(const std::string &text, const std::string &pattern) {
    auto z = Z(pattern + text);
    std::vector<int> lengths(text.size());
    for (int i = 0; i < int(text.size()); ++i)
        lengths[i] = std::min(int(pattern.size()), z[pattern.size() + i]);
    return lengths;
}

// 返回所有匹配起点（0-based），包含重叠；空模式匹配所有边界。
std::vector<int> zSearch(const std::string &text, const std::string &pattern) {
    auto lengths = prefixMatches(text, pattern);
    std::vector<int> positions;
    for (int i = 0; i < int(text.size()); ++i)
        if (lengths[i] == int(pattern.size()))
            positions.push_back(i);
    if (pattern.empty())
        positions.push_back(text.size());
    return positions;
}
```
