# 自适应 Simpson（返回积分值）

被积函数须足够光滑；函数震荡或不光滑时数值积分会失真。 闭区间 [l, r]；误差阈值 eps 按精度调整（默认 1e-9）；递归无深度上限。

与被积函数光滑度相关，典型 O((r-l)/eps^(1/4))。

```cpp
constexpr double SIMPSON_EPS = 1E-9;

// 返回三点 Simpson 估计。
template <class F> double simpson(F f, double l, double r) {
    return (f(l) + 4 * f((l + r) / 2) + f(r)) * (r - l) / 6;
}

// 返回 [l, r] 上自适应积分近似；eps>0，st 须为同区间的 simpson 估计。
template <class F> double simpsonIntegral(F f, double l, double r, double eps, double st) {
    double mid = (l + r) / 2;
    double sl = simpson(f, l, mid);
    double sr = simpson(f, mid, r);
    if (std::abs(sl + sr - st) <= 15 * eps) {
        return sl + sr + (sl + sr - st) / 15;
    }
    return simpsonIntegral(f, l, mid, eps / 2, sl) + simpsonIntegral(f, mid, r, eps / 2, sr);
}

// 返回 [l, r] 上自适应积分近似，使用默认阈值 SIMPSON_EPS。
template <class F> double simpsonIntegral(F f, double l, double r) {
    return simpsonIntegral(f, l, r, SIMPSON_EPS, simpson(f, l, r));
}
```
