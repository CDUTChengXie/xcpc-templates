# 树上删边博弈

输入必须为一棵 n 个点的无向树；节点编号 [0,n)，n>=1；根 root 可选。 edges[i]={u,v} 为第 i 条无向边，边编号从 0 开始；先构造再查询，返回 nullopt 表示无必胜删边。

建树、SG 和寻找操作均 O(n)，空间 O(n)

```cpp
struct TreeCutGame {
    int root;
    std::vector<int> sg, parent,
        edge; // 第 u 项为根子树胜负值、父点、父边原编号；parent[root]=root、edge[root]=-1
    std::vector<std::vector<int>> children; // children[u][j] 是 u 的第 j 个子节点编号
    // 从无向树边表创建；root 是需要保留的根节点
    TreeCutGame(int n, const std::vector<std::pair<int, int>> &edges, int root = 0) : root(root) {
        if (n < 1 || root < 0 || root >= n || edges.size() != size_t(n - 1))
            throw std::invalid_argument("tree");
        std::vector<std::vector<std::pair<int, int>>> g(n);
        for (int i = 0; i < n - 1; ++i) {
            auto [u, v] = edges[i];
            if (u < 0 || u >= n || v < 0 || v >= n || u == v)
                throw std::invalid_argument("edge");
            g[u].emplace_back(v, i);
            g[v].emplace_back(u, i);
        }
        parent.assign(n, -1);
        edge.assign(n, -1);
        sg.assign(n, 0);
        children.resize(n);
        std::vector<int> order{root};
        parent[root] = root;
        for (size_t i = 0; i < order.size(); ++i) {
            int u = order[i];
            for (auto [v, id] : g[u]) {
                if (id == edge[u])
                    continue;
                if (parent[v] != -1)
                    throw std::invalid_argument("cycle");
                parent[v] = u;
                edge[v] = id;
                children[u].push_back(v);
                order.push_back(v);
            }
        }
        if (order.size() != size_t(n))
            throw std::invalid_argument("disconnected");
        for (int i = n - 1; i > 0; --i) {
            int u = order[i];
            sg[parent[u]] ^= sg[u] + 1;
        }
    }
    // 返回整棵根树 SG
    int value() const {
        return sg[root];
    }
    // 返回一条删除后 SG 归零的边编号，不修改树
    std::optional<int> move() const {
        if (value() == 0)
            return std::nullopt;
        int u = root, target = 0;
        while (true) {
            int delta = sg[u] ^ target;
            bool found = false;
            for (int v : children[u]) {
                int next = (sg[v] + 1) ^ delta;
                if (next >= sg[v] + 1)
                    continue;
                if (next == 0)
                    return edge[v];
                u = v;
                target = next - 1;
                found = true;
                break;
            }
            assert(found);
        }
    }
};
```
