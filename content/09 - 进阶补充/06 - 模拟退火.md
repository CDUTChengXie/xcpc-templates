# 模拟退火

先把 Anneal::energy(x) 改成题目目标函数；lo<=hi；结果随机近似，不保证全局最优。 参数（初温、降温率、迭代数）按题目调；多跑几轮保留函数值最小的一次。

每轮 O(迭代数 × 单次求值代价)；多轮总开销线性于轮数，无最坏复杂度保证。

```cpp
struct Anneal {
    // 改成题目要最小化的 f(x)
    static double energy(double x) {
        return std::sin(x) * x + 0.1 * x * x;
    }

    // 返回近似最小值的位置x；lo、hi是搜索范围
    static double solve(double lo, double hi) {
        std::mt19937 rng(std::chrono::steady_clock::now().time_since_epoch().count());
        std::uniform_real_distribution<double> urd(0.0, 1.0);
        double x = lo + urd(rng) * (hi - lo);
        double e = energy(x);
        double best = x, bestE = e;
        double T = 100.0;
        for (int it = 0; it < 100000 && T > 1e-8; it++) {
            double nx = x + (urd(rng) * 2 - 1) * T * 0.1; // 扰动幅度随温度缩小
            nx = std::clamp(nx, lo, hi);
            double ne = energy(nx);
            if (ne < e || urd(rng) < std::exp((e - ne) / T)) {
                x = nx;
                e = ne;
                if (ne < bestE) {
                    best = x;
                    bestE = ne;
                }
            }
            T *= 0.9999; // 降温率
        }
        return best;
    }
};
```
