# 广义斐波那契限取博弈

0<=maxN<=10000、k>=1；堆大小 0..maxN、limit>=0；正常规则不能行动者输，后续限额=k*本次取数。 先构造再查询；limit 是本步最多可取数量；first(n) 要求 n>=1，首步上限 n-1。 返回 nullopt 表示无必胜操作（也含空堆/无合法取法）；非法参数抛 invalid_argument。

预处理 O(maxN²)，空间 O(maxN)，查询 O(1)。

```cpp
// 限取博弈：预处理每个堆大小的最小必胜取数。
struct BoundedTakeGame {
    std::vector<int> need; // need[n] 是堆大小 n 的最小必胜取数，need[0]=0
    // 预处理比例限取，k>=1，下一步上限为 k*本次取数
    BoundedTakeGame(int maxN, i64 k)
        : BoundedTakeGame(maxN, [k](int t) -> i128 {
              if (k < 1)
                  throw std::invalid_argument("k");
              return i128(k) * t;
          }) {
        if (k < 1)
            throw std::invalid_argument("k");
    }
    // 预处理任意规则 nextLimit(t)，返回值必须非负；maxN<=10000
    template <class F>
        requires std::invocable<F, int>
    BoundedTakeGame(int maxN, F nextLimit) {
        if (maxN < 0 || maxN > 10000)
            throw std::invalid_argument("game");
        std::vector<i128> limits(maxN + 1);
        for (int t = 1; t <= maxN; ++t) {
            limits[t] = nextLimit(t);
            if (limits[t] < 0)
                throw std::invalid_argument("limit");
        }
        need.assign(maxN + 1, 0);
        // ponytail: 最小必胜取数逐项试探 O(maxN²)；标准 k=2 大规模改用 Zeckendorf 分解。
        for (int n = 1; n <= maxN; ++n)
            for (int t = 1; t <= n; ++t)
                if (t == n || i128(need[n - t]) > limits[t]) {
                    need[n] = t;
                    break;
                }
    }
    // 返回状态 (n,limit) 的最小必胜取数；空堆和 limit=0 都无法行动
    std::optional<int> move(int n, i64 limit) const {
        if (n < 0 || n >= int(need.size()) || limit < 0)
            throw std::invalid_argument("state");
        if (n == 0 || need[n] > limit)
            return std::nullopt;
        return need[n];
    }
    // 首步不能取完；n 必须为正数且已预处理
    std::optional<int> first(int n) const {
        if (n < 1)
            throw std::invalid_argument("n");
        return move(n, n - 1);
    }
};
```
