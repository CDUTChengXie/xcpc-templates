# 差分约束

每条约束 x_v-x_u<=w，u/v 为变量编号，w 为 int 上限，可为负；负环时无解。 变量下标 0..n-1；返回 `vector<i64>`，solution[u] 是变量 u 的值。 解按所有变量 <=0 规范化，在此前提下逐项最大；空向量表示无解或 n=0 的空系统。

SPFA 最坏 O(nm) 时间，O(n+m) 空间。

```cpp
// 一条差分约束边
struct DiffEdge {
    int v;
    i64 w;
};

// 返回所有变量 <=0 规范化下的最大可行解，负环无解时为空
std::vector<i64> diffConstraints(int n, const std::vector<std::array<int, 3>> &edges) {
    std::vector<std::vector<DiffEdge>> adj(n + 1);
    for (auto [u, v, w] : edges) {
        adj[u].push_back({v, w});
    }
    for (int u = 0; u < n; u++) {
        adj[n].push_back({u, 0});
    }
    std::vector<i64> dis(n + 1, 0);
    std::vector<int> cnt(n + 1, 0);
    std::vector<bool> in(n + 1, true);
    std::queue<int> que;
    for (int u = 0; u <= n; u++) {
        que.push(u);
    }
    while (!que.empty()) {
        int u = que.front();
        que.pop();
        in[u] = false;
        for (auto e : adj[u]) {
            if (dis[e.v] > dis[u] + e.w) {
                dis[e.v] = dis[u] + e.w;
                if (!in[e.v]) {
                    if (++cnt[e.v] > n) {
                        return {};
                    }
                    in[e.v] = true;
                    que.push(e.v);
                }
            }
        }
    }
    dis.resize(n);
    return dis;
}
```
