# 固定环顺序的弦边内外分配

n>=3，环顶点顺序已知且固定；这是固定环顺序的分配，不是任意图平面性判定。 环位置 0..n-1；输入弦按端点在环上的位置记录，不能自环，可共端点；0 为内侧、1 为外侧。 结果按输入弦顺序，无解为 nullopt；无弦时返回存在的空数组。

O(n+m²) 时间与最坏 O(m²) 空间。

```cpp
namespace FixedCycleEmbedding {
    // 返回每条弦画在内/外侧的0/1方案；固定环顺序下不可行返回空
    inline std::optional<std::vector<int>>
    chordSides(int n, const std::vector<std::pair<int, int>> &input) {
        if (n < 3)
            throw std::invalid_argument("cycle needs at least 3 vertices");
        auto chords = input;
        for (auto &[u, v] : chords) {
            if (u < 0 || u >= n || v < 0 || v >= n || u == v)
                throw std::invalid_argument("invalid chord");
            if (u > v)
                std::swap(u, v);
        }
        int m = chords.size();
        std::vector<std::vector<int>> a(m);
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < i; ++j) {
                auto [u, v] = chords[i];
                auto [x, y] = chords[j];
                if ((u < x && x < v && v < y) || (x < u && u < y && y < v)) {
                    a[i].push_back(j);
                    a[j].push_back(i);
                }
            }
        std::vector<int> color(m, -1);
        for (int s = 0; s < m; ++s)
            if (color[s] == -1) {
                std::queue<int> q;
                q.push(s);
                color[s] = 0;
                while (!q.empty()) {
                    int u = q.front();
                    q.pop();
                    for (int v : a[u]) {
                        if (color[v] == -1) {
                            color[v] = color[u] ^ 1;
                            q.push(v);
                        } else if (color[v] == color[u])
                            return std::nullopt;
                    }
                }
            }
        return color;
    }
}
```
