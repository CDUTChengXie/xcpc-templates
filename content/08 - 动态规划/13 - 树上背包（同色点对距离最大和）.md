# 树上背包（同色点对距离最大和）

把恰好 `k` 个点染黑，其余染白，让同色点对之间的距离总和最大。直接枚举点对很难合并，换成按边算：一对点的路径经过某条边，当且仅当它们在边的两侧。

若孩子子树里有 `b` 个黑点、`s` 个白点，跨这条边的同色点对就有 `b*(k-b) + s*(n-k-s)` 对。乘边权便是这条边的贡献。于是子树只需记黑点数，不用记它们具体在哪里。

初始单点可黑可白，内部没有边，贡献为 0。合并孩子时枚举两边的黑点数，计数相加，价值取「两表的和 + 新接边的贡献」的最大值。最后读根的 `dp[root][k]`。

n>=1，0<=k<=n，edges 为 {u,v,边权} 数组且为连通无向树；n²×边权绝对值之和 < 2^58，允许负边权。 点 0..n-1，每条边只传一次；只返回最优值，不返回选点方案；非法树/k 抛 invalid_argument，数值超界抛 overflow_error。

O(n k²) 时间，O(n k) 空间；可将 k 换为 min(k, n-k)。

```cpp
namespace TreeColorPairKnapsack {
    // 返回选 k 个黑点后，同色无序点对树距离和的最大值
    inline i64 solve(int n, const std::vector<std::tuple<int, int, i64>> &edges, int k) {
        if (n < 1 || k < 0 || k > n || int(edges.size()) != n - 1)
            throw std::invalid_argument("invalid tree or k");
        k = std::min(k, n - k);
        std::vector<std::vector<std::pair<int, i64>>> a(n);
        __int128 absSum = 0;
        for (auto [u, v, w] : edges) {
            if (u < 0 || u >= n || v < 0 || v >= n || u == v)
                throw std::invalid_argument("edge");
            a[u].push_back({v, w});
            a[v].push_back({u, w});
            absSum += w < 0 ? -__int128(w) : __int128(w);
        }
        if (absSum * n * n >= (__int128(1) << 58))
            throw std::overflow_error("distance sum bound");
        std::vector<int> parent(n, -1), order{0}, size(n, 1);
        parent[0] = 0;
        std::vector<i64> parentWeight(n);
        for (size_t i = 0; i < order.size(); ++i) {
            int u = order[i];
            for (auto [v, w] : a[u])
                if (parent[v] == -1) {
                    parent[v] = u;
                    parentWeight[v] = w;
                    order.push_back(v);
                }
        }
        if (int(order.size()) != n)
            throw std::invalid_argument("disconnected tree");
        const i64 NEG = -(i64(1) << 60);
        std::vector<std::vector<i64>> dp(n);
        for (int index = n - 1; index >= 0; --index) {
            int u = order[index];
            dp[u].assign(std::min(1, k) + 1, 0);
            for (auto [v, w] : a[u])
                if (parent[v] == u) {
                    int combined = size[u] + size[v];
                    std::vector<i64> next(std::min(combined, k) + 1, NEG);
                    for (int i = 0; i < int(dp[u].size()); ++i)
                        for (int j = 0; j < int(dp[v].size()) && i + j <= k; ++j) {
                            if (dp[u][i] == NEG || dp[v][j] == NEG)
                                continue;
                            i64 black = j, white = size[v] - j;
                            i64 contribution = w * (black * (k - black) + white * (n - k - white));
                            next[i + j] = std::max(next[i + j], dp[u][i] + dp[v][j] + contribution);
                        }
                    size[u] = combined;
                    dp[u] = std::move(next);
                    std::vector<i64>().swap(dp[v]);
                }
        }
        return dp[0][k];
    }
}
```
