# 01 背包

每件物品只有一件。背包最多装 `W`，怎样选才能让总价值最大？设 `old[cap]` 是只看前几件、容量不超过 `cap` 时的最大价值。加入重量为 `w`、价值为 `v` 的下一件，只有两种选择：不拿，或者给它腾出 `w` 的容量。

~~~cpp
next = old;
for (int cap = w; cap <= W; ++cap)
    next[cap] = std::max(old[cap], old[cap - w] + v);
~~~

两种选择都只读上一行。要省掉 `next`，就从大容量往小容量更新：算 `dp[cap]` 时，更小的 `dp[cap-w]` 还没被改过。反过来扫，同一件可能会被拿两次。

不要求装满时，空背包在任何容量下的价值都是 0。若要求恰好装满，初始只有 `dp[0]=0`，其余不可达；最后看 `dp[W]`。

容量非负、重量为正、重量和价值数组等长；价值运算不溢出 i64，有限状态值大于 `NEG_INF`。

O(nW) 时间，O(W) 空间。

```cpp
#ifndef XCPC_DP_NEG_INF
#define XCPC_DP_NEG_INF
constexpr i64 NEG_INF = -(1LL << 60);
#endif

// 默认求不超过 W 的最大价值；exact=true 恰好装满，无解返回 NEG_INF。
i64 knapsack01(const std::vector<i64> &w, const std::vector<i64> &v, int W, bool exact = false) {
    std::vector<i64> dp(W + 1, exact ? NEG_INF : 0);
    dp[0] = 0;
    for (size_t item = 0; item < w.size(); ++item)
        for (int cap = W; cap >= w[item]; --cap)
            if (dp[cap - w[item]] != NEG_INF)
                dp[cap] = std::max(dp[cap], dp[cap - w[item]] + v[item]);
    return dp[W];
}
```

## 完全背包

每种物品可以拿任意多件。最直接的想法是试拿 `k` 件，剩下的容量用以前的种类来装。可在算容量 `cap-w` 时，拿 0 件、1 件、2 件……的情况已经比较过了；给其中最好的方案再添一件，恰好覆盖在 `cap` 下至少拿一件的所有情况。

~~~cpp
next = old;
for (int cap = w; cap <= W; ++cap)
    next[cap] = std::max(old[cap], next[cap - w] + v);
~~~

和 01 背包只差右边的来源：这里是本行的 `next[cap-w]`，不是上一行的 `old[cap-w]`。所以压成一行后容量要正序，让较小容量先算好。初始化仍由题目是否要求恰好装满决定。

容量非负、重量为正，重量与价值数组等长；价值运算不溢出 i64，有限状态值大于 `NEG_INF`。

O(nW) 时间，O(W) 空间。

```cpp
#ifndef XCPC_DP_NEG_INF
#define XCPC_DP_NEG_INF
constexpr i64 NEG_INF = -(1LL << 60);
#endif

// 默认求不超过 W 的最大价值；exact=true 恰好装满，无解返回 NEG_INF。
i64 knapsackComplete(const std::vector<i64> &w, const std::vector<i64> &v, int W,
                     bool exact = false) {
    std::vector<i64> dp(W + 1, exact ? NEG_INF : 0);
    dp[0] = 0;
    for (size_t item = 0; item < w.size(); ++item) {
        if (w[item] > W)
            continue;
        for (int cap = int(w[item]); cap <= W; ++cap)
            if (dp[cap - w[item]] != NEG_INF)
                dp[cap] = std::max(dp[cap], dp[cap - w[item]] + v[item]);
    }
    return dp[W];
}
```

## 多重背包（二进制拆分）

同一种物品有 `count` 件，每件重 `w`、价值 `v`。若拿 `k` 件，就把剩下的 `cap-k*w` 留给前面的种类。用 `old` 记上一种处理完的答案，先写出最直接的做法（不要求装满）：

~~~cpp
next = old;
for (int cap = 0; cap <= W; ++cap)
    for (int k = 1; k <= std::min(count, cap / w); ++k)
        next[cap] = std::max(next[cap], old[cap - k*w] + k*v);
~~~

慢在每个容量都要重试取几件。把 13 件打成 1、2、4、6 四包：前三包能拼出 0 到 7 件，再选最后一包就能拼出 6 到 13 件，一个件数也没漏。一般地，前面的包能拼到 `s`，下一包就最多放 `s+1` 件，两段范围才接得上。因此按 1、2、4……拆，最后不足一包就取余数。

每包现在都是一件 01 物品：重量、价值都乘包内件数，每包倒序扫一次容量。原来每种物品最多要试 `count+1` 种取法，现在只扫 `O(log(count+1))` 包。下面的实现也支持恰好装满；只求不超过容量的最大价值，还可以继续用单调队列优化。

容量非负、重量为正、件数非负，三数组等长；价值运算不溢出 i64，有限状态值大于 `NEG_INF`。

O(n + W·Σ log(1+件数)) 时间，O(W) 空间。

```cpp
#ifndef XCPC_DP_NEG_INF
#define XCPC_DP_NEG_INF
constexpr i64 NEG_INF = -(1LL << 60);
#endif

// 默认求不超过 W 的最大价值；exact=true 恰好装满，无解返回 NEG_INF。
i64 knapsackMultiple(const std::vector<i64> &w, const std::vector<i64> &v,
                     const std::vector<int> &c, int W, bool exact = false) {
    std::vector<i64> dp(W + 1, exact ? NEG_INF : 0);
    dp[0] = 0;
    for (size_t item = 0; item < w.size(); ++item) {
        int remaining = c[item];
        for (i64 block = 1; remaining > 0; block *= 2) {
            int take = int(std::min<i64>(block, remaining));
            remaining -= take;
            if (w[item] > W / take)
                break;
            i64 weight = w[item] * take, value = v[item] * take;
            for (int cap = W; cap >= weight; --cap)
                if (dp[cap - weight] != NEG_INF)
                    dp[cap] = std::max(dp[cap], dp[cap - weight] + value);
        }
    }
    return dp[W];
}
```

## 分组背包

物品分成若干组，每组可以不选，也可以选其中一件。处理一组前，`dp[cap]` 只考虑先前的组。把它复制给 `next`，就已经算了这一组什么都不拿的情况。

再枚举组内每一件：重量为 `w`、价值为 `v`，就用 `dp[cap]+v` 更新 `next[cap+w]`（不超过 `W`）。整组算完才换表。如果拿刚更新的 `next` 继续转移，就可能把同组的两件一起装进去。

容量非负，各组重量为正，组内重量与价值数组等长；价值运算不溢出 i64，有限状态值大于 `NEG_INF`。

O(nW) 时间，O(W) 空间；n 为组数与物品总数之和。

```cpp
#ifndef XCPC_DP_NEG_INF
#define XCPC_DP_NEG_INF
constexpr i64 NEG_INF = -(1LL << 60);
#endif

// 每组 {重量数组, 价值数组}；默认不超过 W，exact=true 恰好装满，无解为 NEG_INF。
i64 knapsackGroup(const std::vector<std::pair<std::vector<i64>, std::vector<i64>>> &groups, int W,
                  bool exact = false) {
    std::vector<i64> dp(W + 1, exact ? NEG_INF : 0);
    dp[0] = 0;
    for (const auto &[weights, values] : groups) {
        auto next = dp;
        for (int cap = 0; cap <= W; ++cap) {
            if (dp[cap] == NEG_INF)
                continue;
            for (size_t item = 0; item < weights.size(); ++item)
                if (weights[item] <= W - cap)
                    next[cap + weights[item]] = std::max(next[cap + weights[item]], dp[cap] + values[item]);
        }
        dp.swap(next);
    }
    return dp[W];
}
```
