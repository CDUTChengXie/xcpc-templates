# 平方段和最小划分（李超树优化）

把数组分段，每段的费用是该段元素和的平方。若最后一刀切在 `j`，这段费用就是 `(S[i]-S[j])²`，其中 `S` 是前缀和。试遍所有 `j<i` 能算对，但要平方时间。

展开平方：`S[i]²` 与切在哪里无关；剩下的是 `(-2*S[j])*S[i] + dp[j] + S[j]²`。把每个已算出的 `j` 看作一条直线，到 `x=S[i]` 查询最低的那条。先放入空前缀的直线，每次先查再插，确保不会用自己转移。数组可含负数，查询坐标不必单调。

`dpSlope(a)`；将数组划成任意个非空连续段，最小化各段元素和的平方之和。允许负数，前缀和、平方和直线求值不溢出 i64，所有有限 DP 值小于 INF。

O(n log n) 时间，O(n) 空间。

```cpp
// 返回最小费用 dp[n]；空数组返回 0
i64 dpSlope(const std::vector<i64> &a) {
    int n = (int)a.size();
    if (n == 0)
        return 0;
    std::vector<i64> S(n + 1, 0);
    for (int i = 0; i < n; i++)
        S[i + 1] = S[i] + a[i];
    // 离散化查询点 x = S[i]，i = 1..n
    std::vector<i64> xs(S.begin() + 1, S.end());
    std::sort(xs.begin(), xs.end());
    xs.erase(std::unique(xs.begin(), xs.end()), xs.end());
    int m = (int)xs.size();

    // Li Chao：维护 min(k*x+b)
    std::vector<i64> K(4 * m + 8, 0), B(4 * m + 8, INF);
    std::vector<bool> has(4 * m + 8, false);
    std::function<void(int, int, int, i64, i64)> ins = [&](int p, int l, int r, i64 k, i64 b) {
        if (!has[p]) {
            has[p] = true;
            K[p] = k;
            B[p] = b;
            return;
        }
        int mid = (l + r) / 2;
        i64 xm = xs[mid], xl = xs[l], xr = xs[r];
        // 端点 + 中点比较，决定谁留在当前节点
        if (k * xm + b < K[p] * xm + B[p]) {
            std::swap(k, K[p]);
            std::swap(b, B[p]);
        }
        if (l == r)
            return;
        if (k * xl + b < K[p] * xl + B[p])
            ins(p * 2, l, mid, k, b);
        else if (k * xr + b < K[p] * xr + B[p])
            ins(p * 2 + 1, mid + 1, r, k, b);
    };
    std::function<i64(int, int, int, i64)> qry = [&](int p, int l, int r, i64 x) {
        if (!has[p])
            return INF;
        i64 res = K[p] * x + B[p];
        if (l == r)
            return res;
        int mid = (l + r) / 2;
        if (x <= xs[mid])
            return std::min(res, qry(p * 2, l, mid, x));
        return std::min(res, qry(p * 2 + 1, mid + 1, r, x));
    };
    // j = 0 先入
    ins(1, 0, m - 1, 0, 0);
    std::vector<i64> dp(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        dp[i] = S[i] * S[i] + qry(1, 0, m - 1, S[i]);
        ins(1, 0, m - 1, -2 * S[i], dp[i] + S[i] * S[i]);
    }
    return dp[n];
}
```
