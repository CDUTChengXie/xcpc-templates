# 多重背包（单调队列）

先看重量为 `w`、价值为 `v`、最多取 `count` 件的一种物品。设 `old` 是处理它之前的 DP，朴素转移是枚举取 `k` 件，对 `old[cap-k*w] + k*v` 取最大值。减去 `k*w` 不会改变容量除以 `w` 的余数，所以只需要在余数同为 `r` 的容量里找：`r, r+w, r+2*w, …`。

当前容量写成 `r+t*w`，原来取 `k` 件就等于从同组第 `p=t-k` 个位置转过来。把与当前位置有关的项提出来：

`old[r+p*w] + (t-p)*v = t*v + (old[r+p*w] - p*v)`，其中 `max(0, t-count) ≤ p ≤ t`。

对固定的 `t`，外面的 `t*v` 不变。括号里的分数只看 `p`，而合法的 `p` 正好是长度至多 `count+1` 的窗口。

同组从小到大扫 `t`，候选区间每次向右滑一格。队首的下标若小于 `t-count`，就意味着用了太多件，要弹掉；新下标 `t` 入队前，从队尾弹掉分数不比它大的候选，因为新候选分数更高或相等，还更晚过期。入队后用队首分数加上 `t*v` 得到当前答案。每个下标至多入队、出队各一次，不再逐个枚举取几件。

三数组等长，重量为正、件数和容量非负，中间运算不溢出 i64。只求不超过容量的最大价值；恰好装满用二进制拆分版。

O(n(W+1)) 时间，O(W+1) 额外空间；n 为物品种数。

```cpp
namespace KnapsackExtra {
    // 每种物品最多取 count[i] 件；返回容量不超过 W 的最大价值
    inline i64 bounded(const std::vector<int> &weight, const std::vector<i64> &value,
                       const std::vector<int> &count, int W) {
        assert(W >= 0 && weight.size() == value.size() && value.size() == count.size());
        std::vector<i64> dp(W + 1, 0);
        for (int i = 0; i < int(weight.size()); ++i) {
            assert(weight[i] > 0 && count[i] >= 0);
            auto old = dp;
            int w = weight[i];
            for (int r = 0; r < w && r <= W; ++r) {
                std::deque<int> q;
                for (int t = 0; r + t * w <= W; ++t) {
                    while (!q.empty() && q.front() < t - count[i])
                        q.pop_front();
                    auto score = [&](int k) { return old[r + k * w] - i64(k) * value[i]; };
                    while (!q.empty() && score(q.back()) <= score(t))
                        q.pop_back();
                    q.push_back(t);
                    dp[r + t * w] = score(q.front()) + i64(t) * value[i];
                }
            }
        }
        return dp[W];
    }

}
```

## 二维费用 01 背包

每件物品有两种消耗，比如重量和体积。只记重量就没法判断剩余体积够不够，所以 `dp[a][b]` 记两项上限分别为 `a,b` 时的最大价值。

不拿就保留原值；拿了消耗 `x,y` 的这一件，就从 `dp[a-x][b-y]` 加上它的价值。两项都装得下才更新；两维都倒着扫，沿用 01 背包读上一轮的写法。

`KnapsackExtra::twoCosts(w1, w2, value, W1, W2)`；三数组等长，两种重量都为正、容量非负，总价值不溢出 i64。

O(n(W1+1)(W2+1)) 时间，O((W1+1)(W2+1)) 空间。

```cpp
namespace KnapsackExtra {
    // 每件最多取一次，同时满足两种容量限制；返回最大价值
    inline i64 twoCosts(const std::vector<int> &w1, const std::vector<int> &w2,
                        const std::vector<i64> &value, int W1, int W2) {
        assert(W1 >= 0 && W2 >= 0 && w1.size() == w2.size() && w1.size() == value.size());
        std::vector<std::vector<i64>> dp(W1 + 1, std::vector<i64>(W2 + 1));
        for (int i = 0; i < int(w1.size()); ++i) {
            assert(w1[i] > 0 && w2[i] > 0);
            for (int a = W1; a >= w1[i]; --a)
                for (int b = W2; b >= w2[i]; --b)
                    dp[a][b] = std::max(dp[a][b], dp[a - w1[i]][b - w2[i]] + value[i]);
        }
        return dp[W1][W2];
    }
}
```

## 依赖背包（父子依赖）

选孩子必须先选父亲。先问一个更小的问题：已经选了 `u`，在它的子树里恰好花 `cap` 容量，最多能拿多少价值？还没处理孩子时，只能选 `u` 自己。

依次合并孩子：跳过它就保留原表；选它就给它分 `b` 容量，把孩子表的价值加到父亲原来花 `a` 的方案上，更新总容量 `a+b`。先算孩子再合并，孩子表里自然只含满足依赖的方案。用重量、价值都为 0 的虚根接住所有根，最后在虚根表中取最大值。

`KnapsackExtra::dependent(parent, weight, value, W)`；三数组等长，parent 构成无环森林，重量为正、容量非负。价值运算不溢出 i64，有限状态值大于 BAD。

O(n(W+1)²) 时间，最坏 O(n(W+1)) 空间。

```cpp
namespace KnapsackExtra {
    constexpr i64 BAD = -(1LL << 60);

    // parent[i] 是必须先选的物品，-1 表示无依赖；返回容量不超过 W 的最大价值
    inline i64 dependent(const std::vector<int> &parent, const std::vector<int> &weight,
                         const std::vector<i64> &value, int W) {
        int n = int(parent.size());
        assert(W >= 0 && weight.size() == parent.size() && value.size() == parent.size());
        std::vector<std::vector<int>> children(n + 1);
        for (int vertex = 0; vertex < n; ++vertex) {
            assert(weight[vertex] > 0 && parent[vertex] >= -1 && parent[vertex] < n &&
                   parent[vertex] != vertex);
            children[parent[vertex] == -1 ? n : parent[vertex]].push_back(vertex);
        }
        auto initial = [&](int vertex) {
            std::vector<i64> row(W + 1, BAD);
            int start = vertex == n ? 0 : weight[vertex];
            if (start <= W)
                row[start] = vertex == n ? 0 : value[vertex];
            return row;
        };
        struct Frame {
            int vertex;
            size_t next;
            std::vector<i64> row;
        };
        std::vector<Frame> frames;
        frames.push_back({n, 0, initial(n)});
        int visited = 1;
        while (true) {
            auto &frame = frames.back();
            if (frame.next < children[frame.vertex].size()) {
                int next = children[frame.vertex][frame.next++];
                ++visited;
                frames.push_back({next, 0, initial(next)});
                continue;
            }
            auto child = std::move(frame.row);
            frames.pop_back();
            if (frames.empty()) {
                assert(visited == n + 1);
                return *std::max_element(child.begin(), child.end());
            }
            auto &current = frames.back().row;
            auto merged = current;
            for (int used = 0; used <= W; ++used)
                if (current[used] != BAD) {
                    for (int added = 0; added <= W - used; ++added)
                        if (child[added] != BAD) {
                            merged[used + added] =
                                std::max(merged[used + added], current[used] + child[added]);
                        }
                }
            current.swap(merged);
        }
    }
}
```

## 混合背包

同一道题里，有的物品只有一件，有的不限量，有的给定件数。它们并不需要三种状态：对重量为 `w` 的物品，即使不限量，容量 `W` 里也最多放 `W/w` 件（向下取整）。

统一成多重背包即可：只有一件就填 `count[i]=1`，限量填实际件数，不限量填 `-1`，函数会换成容量允许的上限。接下来每种只做一次同余组的滑窗转移。

依赖本文件的「多重背包（单调队列）」。

三数组等长，重量为正、容量非负，中间运算不溢出 i64。

O(n(W+1)) 时间，O(n+W+1) 额外空间；n 为物品种数。

```cpp
namespace KnapsackExtra {
    // count[i]=-1 表示不限件数，其他非负值为件数上限；返回容量不超过 W 的最大价值
    inline i64 mixed(const std::vector<int> &weight, const std::vector<i64> &value,
                     const std::vector<int> &count, int W) {
        assert(W >= 0 && weight.size() == value.size() && value.size() == count.size());
        auto limits = count;
        for (int i = 0; i < int(weight.size()); ++i) {
            assert(weight[i] > 0 && limits[i] >= -1);
            if (limits[i] == -1)
                limits[i] = W / weight[i];
        }
        return bounded(weight, value, limits, W);
    }
}
```
