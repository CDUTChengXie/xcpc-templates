# 棋盘国王计数（状压 DP）

在 `n×n` 棋盘恰好放 `k` 个国王，相邻八个方向都不能互相攻击。放下一行时只会碰到上一行，所以不用记整盘：一个整数 `mask` 表示一行，第几位是 1，就在哪一列放国王。

先删去行内有相邻 1 的摆法。上一行是 `b`，当前行是 `a`，那么 `b`、`b<<1`、`b>>1` 分别挡住正下方和两条斜线；`a & (b | (b<<1) | (b>>1))` 为 0 才能相接。

还要记已经用了几个：`dp[used][b]` 是前几行放了 `used` 个、末行为 `b` 的方案数。初始只有空行、0 个这一种。每接一行 `a`，数量加上它的 1 的个数；扫完 `n` 行，把所有末行下恰好用了 `k` 个的方案相加。

0<=n<=10、k>=0、mod>=0；mod=0 为精确计数，否则取模。超出可放数量返回 0，精确计数溢出 i64 抛 overflow_error。

O(S²+n*k*S²) 时间、O(k*S+S²) 空间，S 为无相邻 1 的行掩码数。

```cpp
#ifndef XCPC_WIDA_SMALL_DP_KINGS
#define XCPC_WIDA_SMALL_DP_KINGS

// n*n 棋盘刚好放 k 个互不攻击国王的方案数；mod=0 精确否则取模
// 前置：0<=n<=10，k>=0，mod>=0；k 超过可放上限返回 0
i64 棋盘国王方案数(int n, int k, i64 mod = 0) {
    if (n < 0 || n > 10 || k < 0 || mod < 0)
        throw std::invalid_argument("n/k/mod");
    if (k > ((n + 1) / 2) * ((n + 1) / 2))
        return 0;
    std::vector<int> masks, bits;
    for (int mask = 0; mask < (1 << n); ++mask)
        if (!(mask & (mask << 1))) {
            masks.push_back(mask);
            bits.push_back(std::popcount(unsigned(mask)));
        }
    int states = int(masks.size());
    std::vector<std::vector<int>> previous(states);
    for (int a = 0; a < states; ++a)
        for (int b = 0; b < states; ++b)
            if (!(masks[a] & (masks[b] | (masks[b] << 1) | (masks[b] >> 1))))
                previous[a].push_back(b);
    auto add = [&](i64 &a, i64 b) {
        i128 sum = i128(a) + b;
        if (mod)
            a = i64(sum % mod);
        else {
            if (sum > std::numeric_limits<i64>::max())
                throw std::overflow_error("king count exceeds i64; use mod");
            a = i64(sum);
        }
    };
    std::vector<std::vector<i64>> dp(k + 1, std::vector<i64>(states));
    dp[0][0] = mod ? 1 % mod : 1;
    for (int row = 0; row < n; ++row) {
        std::vector<std::vector<i64>> next(k + 1, std::vector<i64>(states));
        for (int a = 0; a < states; ++a)
            for (int used = bits[a]; used <= k; ++used)
                for (int b : previous[a])
                    add(next[used][a], dp[used - bits[a]][b]);
        dp.swap(next);
    }
    i64 answer = 0;
    for (i64 value : dp[k])
        add(answer, value);
    return answer;
}

#endif
```

## 子序列出现次数（忽略 ASCII 大小写）

在文本中选出若干位置，按顺序拼成模式串，有多少种选法？`dp[j]` 记已经读过的文本中，能拼出模式串前 `j` 个字符的选法。空模式串只有一种选法，所以从 `dp[0]=1` 开始（按模数取余）。

读到新字符时，不用它的方案原样保留；若它等于模式串第 `j` 个字符，还能把它接到每个长度为 `j-1` 的方案上。于是加上 `dp[j-1]`，并把 `j` 从大到小扫，避免同一个文本位置被用两次。

mod>0；按字节匹配，仅折叠 ASCII A..Z。空 pattern 恰有一种空选择，结果取模。

O(|text|*|pattern|) 时间，O(|pattern|) 空间。

```cpp
#ifndef XCPC_WIDA_SMALL_DP_SUBSEQUENCE
#define XCPC_WIDA_SMALL_DP_SUBSEQUENCE

// 返回 pattern 作为 text 子序列出现的次数模 mod（不区分 ASCII 大小写）
// 前置：mod>0；按字节匹配，非 ASCII 不做大小写转换
i64 不区分大小写子序列次数(const std::string &text, std::string pattern, i64 mod = 1000000007) {
    if (mod <= 0)
        throw std::invalid_argument("mod must be positive");
    auto lower = [](unsigned char c) { return c >= 'A' && c <= 'Z' ? c + ('a' - 'A') : int(c); };
    for (char &c : pattern)
        c = char(lower(static_cast<unsigned char>(c)));
    std::vector<i64> dp(pattern.size() + 1);
    dp[0] = 1 % mod; // 空 pattern 恰有一种空选择；mod=1 时返回 0
    for (unsigned char c : text)
        for (size_t j = pattern.size(); j > 0; --j)
            if (lower(c) == static_cast<unsigned char>(pattern[j - 1]))
                dp[j] = i64((i128(dp[j]) + dp[j - 1]) % mod);
    return dp.back();
}

#endif
```

## 最长合法括号子串

字符串只能含 ()[]；空串或无解返回 [0,0)，其他字符抛 invalid_argument。

O(n) 时间与空间。

```cpp
#ifndef XCPC_WIDA_SMALL_DP_BRACKETS
#define XCPC_WIDA_SMALL_DP_BRACKETS

// 最长正确连续括号子串 [l,r)；同长取最早，无解 [0,0)
// 前置：s 只含 ()[]，否则抛 std::invalid_argument（空串允许）
std::pair<size_t, size_t> 最长正确括号子串(const std::string &s) {
    std::vector<size_t> dp(s.size());
    std::pair<size_t, size_t> answer{0, 0};
    for (size_t i = 0; i < s.size(); ++i) {
        char c = s[i];
        if (c != '(' && c != ')' && c != '[' && c != ']')
            throw std::invalid_argument("only ()[] allowed");
        if (c == '(' || c == '[')
            continue;
        size_t suffix = i ? dp[i - 1] : 0;
        if (suffix >= i)
            continue; // i-1-suffix 可能为负（含 i=0）
        size_t opening = i - 1 - suffix;
        if ((c == ')' && s[opening] == '(') || (c == ']' && s[opening] == '[')) {
            dp[i] = suffix + 2 + (opening ? dp[opening - 1] : 0);
            if (dp[i] > answer.second - answer.first)
                answer = {i + 1 - dp[i], i + 1};
        }
    }
    return answer;
}

#endif
```

## 数位 DP：排除 4 与相邻 62

要数闭区间 `[l,r]`，先只做前缀计数 `F(x)`，最后相减 `F(r)-F(l-1)`。从高位向低位填数：4 永远不能填，2 只有在上一位是 6 时才不能填，所以不用记完整前缀，只记「上一位是不是 6」和「是否还贴着上界」。

空前缀有一种，既不是以 6 结尾，也没有低于上界。每填一个允许的数字，就把方案数加进新状态。这里补前导零不会制造 4 或 62，因而无需另设开始标记：全零就是合法整数 0。末位填完，把四种状态求和。

0<=l<=r，数字 0 计入；非法区间抛 invalid_argument。

O(十进制位数*10) 时间，O(1) 空间。

```cpp
#ifndef XCPC_WIDA_SMALL_DP_DIGIT_RULE
#define XCPC_WIDA_SMALL_DP_DIGIT_RULE

// 闭区间 [l,r] 内不含数字 4、且不含相邻 62 的非负整数个数（0 计入）
// 前置：0<=l<=r
i64 排除四和六二的区间计数(i64 l, i64 r) {
    if (l < 0 || r < l)
        throw std::invalid_argument("require 0 <= l <= r");
    auto prefix = [](i64 x) {
        if (x < 0)
            return i64(0); // [0,-1] 为空，l=0 时无需特殊处理数字 0
        i64 dp[2][2] = {}; // [前一位是否 6][是否贴上界]
        dp[0][1] = 1;
        for (char c : std::to_string(x)) {
            i64 next[2][2] = {};
            for (int six = 0; six < 2; ++six)
                for (int tight = 0; tight < 2; ++tight)
                    for (int digit = 0; digit <= (tight ? c - '0' : 9); ++digit)
                        if (digit != 4 && !(six && digit == 2))
                            next[digit == 6][tight && digit == c - '0'] += dp[six][tight];
            for (int six = 0; six < 2; ++six)
                for (int tight = 0; tight < 2; ++tight)
                    dp[six][tight] = next[six][tight];
        }
        return dp[0][0] + dp[0][1] + dp[1][0] + dp[1][1];
    };
    return prefix(r) - prefix(l - 1);
}

#endif
```

## 十进制数字出现次数

0<=d<=9；不计前导零，0 本身算一位；x<0 返回 0，结果为 i128。

O(十进制位数) 时间，O(1) 空间。

```cpp
#ifndef XCPC_WIDA_SMALL_DP_DIGIT_COUNT
#define XCPC_WIDA_SMALL_DP_DIGIT_COUNT

// [0,x] 内十进制数字 d 出现的总次数；不计前导零，数字 0 本身算一位
// 前置：0<=d<=9；x<0 返回 0
i128 数字出现总次数(i64 x, int d) {
    if (d < 0 || d > 9)
        throw std::invalid_argument("digit must be 0..9");
    if (x < 0)
        return 0;
    i128 answer = d == 0 ? 1 : 0;
    for (i128 place = 1; place <= x; place *= 10) {
        i128 high = i128(x) / (place * 10), current = i128(x) / place % 10, low = i128(x) % place;
        if (d == 0) {
            if (high)
                answer += (high - 1) * place + (current == 0 ? low + 1 : place);
        } else
            answer += high * place + (current > d ? place : current == d ? low + 1 : 0);
    }
    return answer;
}

#endif
```
