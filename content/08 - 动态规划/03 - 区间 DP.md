# 矩阵链乘最少代价

矩阵顺序固定，只能改变括号。问 `[l,r]` 这条链最后一次乘法把哪两段乘到了一起？若断在 `k` 后面，先各自算出 `[l,k]` 和 `[k+1,r]` 的最小代价，再加上两个结果矩阵相乘的代价。

`dp[l][r] = min(dp[l][k] + dp[k+1][r] + d[l]*d[k+1]*d[r+1])`，其中 `l ≤ k < r`。单个矩阵不用乘，`dp[i][i]=0`；两侧都比原区间短，所以按区间长度从小到大填表。

`matrixChainMul(d)`；第 i 个矩阵尺寸为 d[i]×d[i+1]，边长为正。所有乘积与费用不溢出 i64，最优费用小于 INF。

n 为矩阵个数；O(n³) 时间，O(n²) 空间。

```cpp
// 矩阵链乘：第 i 个矩阵尺寸 d[i]×d[i+1]，返回最少标量乘法次数
i64 matrixChainMul(const std::vector<int> &d) {
    int n = (int)d.size() - 1;
    if (n <= 0)
        return 0;
    std::vector<std::vector<i64>> dp(n, std::vector<i64>(n, 0));
    for (int len = 2; len <= n; len++) { // len 必须在最外层
        for (int l = 0; l + len <= n; l++) {
            int r = l + len - 1;
            dp[l][r] = INF;
            for (int k = l; k < r; k++) {
                i64 cost = dp[l][k] + dp[k + 1][r] + (i64)d[l] * d[k + 1] * d[r + 1];
                dp[l][r] = std::min(dp[l][r], cost);
            }
        }
    }
    return dp[0][n - 1];
}
```

## 最少插入字符成为回文

只允许插入字符。令 `dp[l][r]` 是把这段串变成回文最少要插几个，空串和单字符都是 0。若两端相同，它们可以配成一对，直接看中间。

若两端不同，最终要么在右边插一个字符配左端，要么在左边插一个字符配右端。因此 `dp[l][r] = 1 + min(dp[l+1][r], dp[l][r-1])`。先算短串，再算长串，整串对应的格子就是答案。

`minPalindromeInsert(s)`；按字节比较，允许在任意位置插入字符。

O(n²) 时间与空间，n 为字符串长度。

```cpp
// 在任意位置插入字符使 s 成为回文，返回最少插入次数
i64 minPalindromeInsert(const std::string &s) {
    int n = (int)s.size();
    if (n == 0)
        return 0;
    std::vector<std::vector<int>> dp(n, std::vector<int>(n, 0));
    for (int i = n - 2; i >= 0; i--) {
        for (int j = i + 1; j < n; j++) {
            if (s[i] == s[j]) {
                dp[i][j] = (j - i == 1 ? 0 : dp[i + 1][j - 1]);
            } else {
                dp[i][j] = std::min(dp[i + 1][j], dp[i][j - 1]) + 1;
            }
        }
    }
    return dp[0][n - 1];
}
```
