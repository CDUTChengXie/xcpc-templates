# 不含相邻相等数字的计数（数位 DP）

数 `[0,N]` 中相邻数位都不同的整数。逐个检查整数太慢；改成从高位起填数字。填到位置 `pos` 时，后面可以怎么填，只取决于上一位是什么、前缀是否等于上界，以及有效数字是否已经开始。

若还贴着上界，本位最多填 `N[pos]`；填得更小，后面便可自由选 0 到 9。开始后不能再填与上一位相同的数字；开始前填 0 只是补位，不参与比较。填完所有位就贡献一种，因此全程没开始的路径也正好把 0 算一次。相同状态的后续答案可直接复用。

`countLE(N)`；N 为非空十进制字符串，允许前导零，有效位数不超过 18。前导零不参与相邻比较，0 计入。

L 为字符串长度；O(L×10²) 时间，O(L×10) 空间。

```cpp
// 返回闭区间 [0,N] 内没有相邻相等数字的整数个数
i64 countLE(const std::string &N) {
    constexpr int LASTS = 11;
    int len = int(N.size());
    std::vector<i64> memo(size_t(len) * LASTS * 2 * 2, -1);
    auto cell = [&](int pos, int last, int tight, int started) -> i64 & {
        return memo[((size_t(pos) * LASTS + last + 1) * 2 + tight) * 2 + started];
    };

    std::function<i64(int, int, bool, bool)> dfs = [&](int pos, int last, bool tight,
                                                       bool started) -> i64 {
        if (pos == len) {
            return 1; // 0 也算一个（数位序列为空）
        }
        i64 &res = cell(pos, last, tight, started);
        if (res != -1) {
            return res;
        }
        res = 0;
        int lim = tight ? N[pos] - '0' : 9;
        for (int d = 0; d <= lim; d++) {
            bool nt = tight && (d == lim);
            if (!started) {
                // d == 0 仍是前导零，不记录上一位
                res += dfs(pos + 1, d == 0 ? -1 : d, nt, d != 0);
            } else if (d != last) {
                res += dfs(pos + 1, d, nt, true);
            }
        }
        return res;
    };
    return dfs(0, -1, true, false);
}
```
