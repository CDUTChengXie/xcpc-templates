# 01 背包方案计数

现在问的不是最大价值，而是有多少种选法能恰好装满。`dp[cap]` 记总重量恰好是 `cap` 的方案数。没放物品时，只有容量 0 有一种选法：什么都不拿。

按最后一件拿没拿来分：没拿的已经在 `dp[cap]` 里；拿了的，删去这件后恰好重 `cap-w`。两类不重叠，所以用加法 `dp[cap] += dp[cap-w]`，而不是取最大值。容量倒序，保证这件只用一次。

重量为正、容量非负，取模前的加法也不能溢出 i64。

O(nW) 时间，O(W) 空间。

```cpp
// 01 背包恰好装满 W 的方案数；无解为 0，mod<=1 不取模
i64 count01(const std::vector<i64> &w, int W, i64 mod = 0) {
    std::vector<i64> dp(W + 1, 0);
    dp[0] = 1;
    for (size_t i = 0; i < w.size(); i++) {
        for (int j = W; j >= w[i]; j--) { // 倒序：每件只用一次
            dp[j] += dp[j - w[i]];
            if (mod > 1)
                dp[j] %= mod;
        }
    }
    return dp[W];
}
```

## 完全背包方案计数

同一种物品能重复拿，要数的是恰好装满的组合，不是装入顺序。`dp[0]=1`；处理重量 `w` 时，所有至少拿一件的方案都能唯一地删去一件 `w`，变成当前这轮里总重量为 `cap-w` 的方案。

因此仍做 `dp[cap] += dp[cap-w]`，但容量正序。同一种类一次处理完，不会把先拿 A 再拿 B 和先 B 后 A 算两遍。不同下标仍视作不同种类。

重量为正、容量非负，取模前的加法也不能溢出 i64。

O(nW) 时间，O(W) 空间。

```cpp
// 恰好装满 W 的组合数；无解为 0，mod<=1 不取模
i64 countComplete(const std::vector<i64> &w, int W, i64 mod = 0) {
    std::vector<i64> dp(W + 1, 0);
    dp[0] = 1;
    for (size_t i = 0; i < w.size(); i++) {
        if (w[i] > W)
            continue;                     // 先比较 i64 重量，避免转为 int 时截断
        for (int j = w[i]; j <= W; j++) { // 正序：允许重复
            dp[j] += dp[j - w[i]];
            if (mod > 1)
                dp[j] %= mod;
        }
    }
    return dp[W];
}
```

## 01 背包方案恢复

求一组恰好装满且价值最大的物品。只存最终的 `dp[W]` 看不出选过谁；算第 `i` 件时，如果拿它比不拿更好，就记 `take[i][cap]=1`。平局保留不拿的方案，仍然最优。

从最后一件和容量 `W` 倒推：标记为 1 就记下这件，并减掉它的重量；否则容量不变。无论拿不拿，下一步都回到上一件。最后翻转下标；无解和 `W=0` 都返回空数组。

重量为正、容量非负，重量与价值数组等长；价值运算不溢出 i64，有限状态值大于 `NEG_INF`。

O(nW) 时间和空间。

```cpp
#ifndef XCPC_DP_NEG_INF
#define XCPC_DP_NEG_INF
constexpr i64 NEG_INF = -(1LL << 60);
#endif

// 返回一组恰好装满且价值最大的物品下标（从 0 开始）；无解或 W=0 返回空数组
std::vector<int> recover01(const std::vector<i64> &w, const std::vector<i64> &v, int W) {
    int n = (int)w.size();
    // take[i][j]：是否取第 i 件
    std::vector<std::vector<char>> take(n + 1, std::vector<char>(W + 1, 0));
    std::vector<i64> dp(W + 1, NEG_INF);
    dp[0] = 0;
    for (int i = 1; i <= n; i++) {
        // 倒序保证同一件物品不被重复取用
        for (int j = W; j >= w[i - 1]; j--) {
            if (dp[j - w[i - 1]] != NEG_INF && dp[j - w[i - 1]] + v[i - 1] > dp[j]) {
                dp[j] = dp[j - w[i - 1]] + v[i - 1];
                take[i][j] = 1;
            }
        }
    }
    std::vector<int> res;
    int j = W;
    for (int i = n; i >= 1 && j > 0; i--) {
        if (take[i][j]) {
            res.push_back(i - 1);
            j -= (int)w[i - 1];
        }
    }
    std::reverse(res.begin(), res.end());
    return res;
}
```
