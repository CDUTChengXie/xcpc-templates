# 分治决策单调性优化

把前 `i` 项分成恰好 `g` 个非空连续段。若最后一段是 `[j,i)`，之前的 `j` 项就必须恰好分成 `g-1` 段；枚举 `j` 取最小值即可。初始只有空前缀能分成 0 段。朴素做法每层要试平方级的分割点。

若已证明最优分割点随右端点不向左走，就先算本层中点，设它选了 `best`。中点左边的答案只用查到 `best`，右边只用从 `best` 往后查，再对两边递归。不能证明这个性质时，不能据此删掉候选。

`DivideDP::partition(n, groups, cost)`；cost(j,i) 为 [j,i) 的费用。n、groups 非负，所有区间费用与有限 DP 值的绝对值 < 2^59，不支持禁止某个区间。

递推：`dp[g][i] = min(dp[g-1][j] + cost(j,i))`，g-1<=j<i。固定 g，最优 j（并列取最小）必须随 i 不减。

O(groups × n log n × 单次费用查询)，空间 O(n)。

```cpp
namespace DivideDP {
    constexpr i64 BIG = (1LL << 60);

    // 将 [0,n) 分成恰好 groups 个非空连续段；返回最小总费用，无解返回 BIG
    // cost(l,r) 返回 [l,r) 的费用；必须保证最优分割点随右端点不减
    template <class Cost> i64 partition(int n, int groups, Cost cost) {
        assert(n >= 0 && groups >= 0);
        if (groups > n)
            return BIG;
        std::vector<i64> previous(n + 1, BIG), current(n + 1, BIG);
        previous[0] = 0;
        for (int layer = 1; layer <= groups; ++layer) {
            std::fill(current.begin(), current.end(), BIG);
            auto work = [&](auto &&self, int left, int right, int optL, int optR) -> void {
                if (left > right)
                    return;
                int mid = (left + right) / 2, best = -1;
                for (int k = optL; k <= std::min(optR, mid - 1); ++k) {
                    if (previous[k] == BIG)
                        continue;
                    i64 candidate = previous[k] + cost(k, mid);
                    if (candidate < current[mid]) {
                        current[mid] = candidate;
                        best = k;
                    }
                }
                assert(best != -1);
                self(self, left, mid - 1, optL, best);
                self(self, mid + 1, right, best, optR);
            };
            work(work, layer, n, layer - 1, n - 1);
            previous.swap(current);
        }
        return previous[n];
    }
}
```
