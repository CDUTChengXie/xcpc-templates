# 一维决策单调性优化

仍是枚举最后一段 `[j,i)`，但这次没有固定段数，`dp[j]` 是在同一行刚算出的答案，没法像分层 DP 那样先算中点。可以从左往右算，同时记下每个前驱从哪个位置起最划算。

前提是两个前驱的优劣最多交替一次：新前驱一旦追上旧前驱，就不会再落后。加入新前驱时，若它连队尾候选的起点都能赢，队尾就不再有用；否则二分找到它首次追上的位置，若始终追不上则丢弃。算到 `i` 时，队首给出这一项的前驱。

`OnlineMongeDP::solve(n, cost)`；n>=0，cost(j,i) 为 [j,i) 的费用。候选转移值绝对值须 < 2^60，否则抛 overflow_error。

递推：`dp[i] = min(dp[j] + cost(j,i))`，dp[0]=0，0<=j<i。对任意两个候选，较大的 j 一旦不劣于较小的 j，对所有后续 i 都必须继续不劣。

cost 为 O(1) 时 O(n log n) 时间、O(n) 空间。

```cpp
namespace OnlineMongeDP {
    struct Result {
        std::vector<i64> dp;    // dp[i] 为前 i 项的最小总费用，dp[0] = 0
        std::vector<int> choice; // choice[i] 为上一处切分点 j，末段是 [j,i)；choice[0] = -1
    };
    // 返回一维最小费用DP和每个位置的前驱；cost(j,i)由题目提供
    template <class Cost> Result solve(int n, Cost cost) {
        if (n < 0)
            throw std::invalid_argument("negative n");
        Result r{std::vector<i64>(n + 1), std::vector<int>(n + 1, -1)};
        struct Candidate {
            int j, from;
        };
        std::deque<Candidate> q;
        if (n)
            q.push_back({0, 1});
        auto value = [&](int j, int i) -> i64 {
            __int128 x = __int128(r.dp[j]) + cost(j, i);
            if (x <= -(__int128(1) << 60) || x >= (__int128(1) << 60))
                throw std::overflow_error("DP bound");
            return i64(x);
        };
        for (int i = 1; i <= n; ++i) {
            while (q.size() > 1 && q[1].from <= i)
                q.pop_front();
            int j = q.front().j;
            r.dp[i] = value(j, i);
            r.choice[i] = j;
            if (i == n)
                break;
            while (!q.empty()) {
                int start = std::max(i + 1, q.back().from);
                if (value(i, start) <= value(q.back().j, start))
                    q.pop_back();
                else
                    break;
            }
            if (q.empty()) {
                q.push_back({i, i + 1});
                continue;
            }
            j = q.back().j;
            if (value(i, n) > value(j, n))
                continue;
            int lo = std::max(i + 1, q.back().from), hi = n;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (value(i, mid) <= value(j, mid))
                    hi = mid;
                else
                    lo = mid + 1;
            }
            q.push_back({i, lo});
        }
        return r;
    }
}
```
